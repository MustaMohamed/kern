## Intent

Part 1 took one typed go from a ticket to a draft PR. The user wants the run to carry on to a PR a reviewer can pick up: "the autopilot should finish the work until the PR is ready without CI issue". Reviews are not part of the run: "the comments and review cycles takes time, the thread can't wait until all reviewer finish, maybe we can create another skill watch the PR and the comments until resolving everything". When a change needs it, the run proves it on the running app: "testing the actual work with screenshots or recorded video".

Superpowers stays on until the user trusts kern, as in part 1. The real round on the user's projects runs once, after all six projects.
