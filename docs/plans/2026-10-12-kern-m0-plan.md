# kern M0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the kern repo as a valid Claude Code plugin and marketplace with licensing, lint, routing evals and CI, all green on a placeholder skill.

**Architecture:** One git repo at `~/Code/projects/kern` that is both the plugin (`.claude-plugin/plugin.json`) and its own marketplace (`.claude-plugin/marketplace.json`, `source: "./"`). Dev tooling is zero-dependency Node ESM (`scripts/*.mjs`, tested with `node --test`) plus bash (`scripts/fetch-upstream`, tested with bats). Upstream sources that later milestones port from are cloned at pinned commits into a gitignored `.upstream/`.

**Tech Stack:** Node 22 (built-in `node:test`, no npm dependencies), bash 3.2+ (macOS default) and POSIX tools, bats-core, shellcheck, git, `gh`, Claude Code 2.1.296 (`claude plugin validate --strict`).

**Spec:** `docs/specs/2026-10-12-kern-design.md` (sections 2, 3.4, 11, 12, 14) and `docs/specs/2026-10-12-kern-m1-m2-skills.md`. Shared names and signatures: `docs/plans/contract.md`. Executors read the spec, the contract and this plan.

## Global Constraints

- Plugin name `kern`; skills invoked as `/kern:<skill>` (D-1).
- Claude Code only (D-3). Minimum Claude Code version for development: 2.1.295 (hook `onFailure` needs it); pinned in CI: 2.1.296.
- kern's own licence: MIT. Copyright line: `Copyright (c) 2026 Mustafa Mohamed`.
- Sources and pins: superpowers 6.4.1, MIT, 2025 Jesse Vincent, commit `5bf4e78011075bcfc0dc295f0724994cd123ee71`; cursor/plugins `pstack/` 0.15.17, MIT, 2026 Lauren Tan, `11713c6`; mattpocock/skills 1.3.1, MIT, 2026 Matt Pocock, `49dd158`; addyosmani/agent-skills 0.6.12, MIT, 2025 Addy Osmani, `1be8e34`; caveman 3.2.0, Apache-2.0, 2026 Julius Brussee, installed cache.
- "Caveman", "ultracave" and "megacave" are trademarks: never a name, file name, mode or skill in kern. The mode is `terse`.
- NOTICE reproduces caveman's NOTICE content (Apache-2.0 section 4d). Files modified from an Apache-2.0 source carry a header line saying they were changed. Scripts adapted from any source carry a one-line source comment. SKILL.md files carry none; the NOTICE map covers them.
- Description limits: auto skills at most 300 chars with a trigger phrase, at most 1,500 chars total; path and slash skills at most 120 chars; agents at most 150 chars; auto skills plus agents at most 2,500 chars.
- Lint rule 8: no machine paths or personal names in shipped files (`skills/`, `agents/`, `kernel/`, `modes/`, `hooks/`).
- Lint rule 11: no long dashes (U+2013, U+2014) and no curly quotes (U+2018, U+2019, U+201C, U+201D) in shipped files, `README.md` and `CHANGELOG.md`.
- Versioning: semver; Keep-a-Changelog with an `Unreleased` section; `plugin.json`, `marketplace.json` and the newest CHANGELOG release agree.
- Routing evals: every auto skill has a case file with at least 3 positive prompts, 2 negative prompts and 1 behavioural eval; the rank-1 rate floor only rises.
- Commits in this repo: subject `M0: <imperative summary>`, 72 chars or fewer; body says why; no attribution trailers; stage named paths only (`git add -- <paths>`), never `-A`. Pushes and the GitHub repo creation happen only after the user says yes.
- Prose in every file follows unslop: answer first, no filler, no long dashes, no curly quotes.

## Review Focus

1. **A skill file with Windows line endings.** A SKILL.md saved with `\r\n` must parse the same as `\n`; otherwise lint reports a missing frontmatter on a valid file. Pinned in Task 5, test `parses CRLF frontmatter`.
2. **A description that is quoted, or carries a colon.** `description: "Use when: x"` must lint by its unquoted text and length. Pinned in Task 5, test `strips quotes and keeps colons in values`.
3. **An eval prompt that shares no vocabulary with any skill.** The runner must report "shares no vocabulary", not crash on a zero vector or divide by zero. Pinned in Task 7, test `zero-score prompt is an error, not a crash`.
4. **A CHANGELOG with no release yet, only `Unreleased`.** `check-version` must compare against the manifests' version and fail with a clear message, not throw. Pinned in Task 6, test `no release heading is a clear failure`.
5. **`fetch-upstream` re-run on a tree already at the pin, or with a missing commit.** A re-run must not re-clone; a missing commit exits 3 and leaves no half-filled directory. Pinned in Task 2, tests `second run is a no-op` and `missing commit exits 3 and removes the partial clone`.

## Port-task convention (used from M1 on; stated here so all three plans share it)

A prose file ported from an upstream source names the source file and line range under `.upstream/<source>/`, lists the required headings in order, states the adaptation rules (no source tags, no personal names or machine paths, kern vocabulary, unslop rules, no long dashes or curly quotes), gives the full text of anything that is a contract (frontmatter, `## Steps`, kernel text, mode rules, injected lines, agent return formats), and ends with a check command: lint, `grep` for each required heading, and a size bound with `wc -c`.

- [ ] **Step 3: Write `scripts/fetch-upstream`**

```bash
#!/usr/bin/env bash
# Fills .upstream/ with the pinned source trees that kern files are ported from. Dev-only; hooks never run it.
set -euo pipefail

root=$(cd "$(dirname "$0")/.." && pwd)
dest="${KERN_UPSTREAM_DIR:-$root/.upstream}"
mkdir -p "$dest"

pin() { # key -> "url sha" for git sources
  case "$1" in
    superpowers) echo "https://github.com/obra/superpowers.git 5bf4e78011075bcfc0dc295f0724994cd123ee71" ;;
    pstack) echo "https://github.com/cursor/plugins.git 11713c6" ;;
    pocock) echo "https://github.com/mattpocock/skills.git 49dd158" ;;
    addy) echo "https://github.com/addyosmani/agent-skills.git 1be8e34" ;;
    *) return 1 ;;
  esac
}

override() { # key suffix default
  local var
  var="KERN_UPSTREAM_$(printf '%s' "$1" | tr '[:lower:]' '[:upper:]')_$2"
  printf '%s' "${!var:-$3}"
}

clone_at() { # key url sha
  local key=$1 url=$2 sha=$3 dir="$dest/$1"
  if [ -d "$dir/.git" ]; then
    local want
    want=$(git -C "$dir" rev-parse --verify --quiet "$sha^{commit}" || true)
    if [ -n "$want" ] && [ "$(git -C "$dir" rev-parse HEAD)" = "$want" ]; then
      echo "$key: already at $sha"
      return 0
    fi
  fi
  rm -rf "$dir"
  if ! git clone --quiet "$url" "$dir"; then
    rm -rf "$dir"
    echo "$key: clone failed: $url" >&2
    return 3
  fi
  if ! git -C "$dir" checkout --quiet --detach "$sha" 2>/dev/null; then
    rm -rf "$dir"
    echo "$key: commit $sha not found in $url" >&2
    return 3
  fi
  echo "$key: $url @ $sha"
}

copy_from() { # key src...
  local key=$1 dir="$dest/$1"
  shift
  rm -rf "$dir"
  mkdir -p "$dir"
  local src
  for src in "$@"; do
    if [ ! -e "$src" ]; then
      rm -rf "$dir"
      echo "$key: source missing: $src" >&2
      return 3
    fi
    cp -R "$src" "$dir"/
  done
  echo "$key: copied"
}

fetch() {
  local key=$1 url sha
  case "$key" in
    superpowers|pstack|pocock|addy)
      read -r url sha <<<"$(pin "$key")"
      url=$(override "$key" URL "$url")
      sha=$(override "$key" SHA "$sha")
      local rc=0
      clone_at "$key" "$url" "$sha" || rc=$?
      if [ "$rc" -ne 0 ] && [ "$key" = superpowers ] && [ -z "${KERN_UPSTREAM_SUPERPOWERS_URL:-}" ]; then
        echo "superpowers: falling back to the installed cache" >&2
        copy_from superpowers "$HOME/.claude/plugins/cache/claude-plugins-official/superpowers/6.4.1/."
        return
      fi
      return "$rc"
      ;;
    caveman)
      local src
      src=$(override caveman SRC "$HOME/.claude/plugins/cache/caveman/caveman/3.2.0")
      copy_from caveman "$src/."
      ;;
    local)
      local src
      src=$(override local SRC "")
      if [ -n "$src" ]; then
        copy_from local "$src/."
      else
        copy_from local "$HOME/.claude/skills/recall" "$HOME/.claude/skills/unslop" "$HOME/.claude/skills/no-comments" "$HOME/.claude/agents/comment-sicko.md"
      fi
      ;;
    *)
      echo "unknown source: $key (use superpowers pstack pocock addy caveman local)" >&2
      exit 2
      ;;
  esac
}

keys=("$@")
[ ${#keys[@]} -gt 0 ] || keys=(superpowers pstack pocock addy caveman local)
status=0
for k in "${keys[@]}"; do
  fetch "$k" || status=$?
done
exit "$status"
```

Note: `copy_from superpowers "$cache/."` copies the directory's contents; `cp -R "$src" "$dir"/` with a trailing `/.` copies contents, and without it copies the named directory into `$dir`, which is what the `local` key wants (`.upstream/local/recall/...`).

```js
import { test } from 'node:test';
import assert from 'node:assert/strict';
import { readFileSync, existsSync } from 'node:fs';

const read = (p) => readFileSync(new URL(`../${p}`, import.meta.url), 'utf8');

function upstreamRows() {
  return read('UPSTREAM.md').split('\n')
    .filter((l) => /^\| [a-z]+ \|/.test(l))
    .map((l) => l.split('|').slice(1, -1).map((c) => c.trim()));
}

test('kern itself is MIT', () => {
  assert.match(read('LICENSE'), /^MIT License\n\nCopyright \(c\) 2026 Mustafa Mohamed/);
});

test('every upstream source has a licence file and a NOTICE entry', () => {
  const rows = upstreamRows();
  assert.deepEqual(rows.map((r) => r[0]).sort(), ['addy', 'caveman', 'pocock', 'pstack', 'superpowers']);
  const notice = read('NOTICE');
  for (const [key, , , , copyright, , url] of rows) {
    assert.ok(existsSync(new URL(`../licenses/${key}.LICENSE`, import.meta.url)), `licenses/${key}.LICENSE`);
    assert.ok(notice.includes(url), `NOTICE names ${url}`);
    assert.ok(notice.includes(copyright), `NOTICE carries "${copyright}"`);
  }
});

test('NOTICE reproduces caveman NOTICE verbatim', () => {
  assert.ok(read('NOTICE').includes(read('licenses/caveman.NOTICE').trim()));
});

test('caveman licence is Apache-2.0', () => {
  assert.match(read('licenses/caveman.LICENSE'), /Apache License\s+Version 2\.0, January 2004/);
});

test('NOTICE has a file map section', () => {
  assert.match(read('NOTICE'), /^## File map$/m);
});
```

```js
// Minimal frontmatter reader for kern files: single-line `key: value` pairs only.
export function parseFrontmatter(src) {
  const text = src.replace(/\r\n/g, '\n');
  const m = text.match(/^---\n([\s\S]*?)\n---[ \t]*(?:\n|$)/);
  if (!m) return { data: {}, body: text, error: 'no frontmatter block' };
  const data = {};
  for (const line of m[1].split('\n')) {
    if (!line.trim() || line.trimStart().startsWith('#')) continue;
    const kv = line.match(/^([A-Za-z][A-Za-z0-9_-]*):[ \t]*(.*)$/);
    if (!kv) return { data, body: text.slice(m[0].length), error: `unparsed frontmatter line (use single-line values): ${line}` };
    let value = kv[2].trim();
    if (value === '>' || value === '|' || value === '>-' || value === '|-') {
      return { data, body: text.slice(m[0].length), error: `key ${kv[1]} uses a block scalar; use single-line values` };
    }
    if ((value.startsWith('"') && value.endsWith('"')) || (value.startsWith("'") && value.endsWith("'"))) value = value.slice(1, -1);
    data[kv[1]] = value;
  }
  return { data, body: text.slice(m[0].length), error: null };
}
```

```js
// kern lint rules (design spec 11.2). Pure checks over a loaded model; the CLI is scripts/lint-skills.mjs.
// Rule set informed by addyosmani/agent-skills scripts/lib/skill-lint.js (MIT); the code is written for kern.
import { readFileSync, readdirSync, existsSync, statSync } from 'node:fs';
import { join, relative } from 'node:path';
import { parseFrontmatter } from './frontmatter.mjs';

export const SKILL_KEYS = new Set(['name', 'description', 'when_to_use', 'argument-hint', 'arguments', 'disable-model-invocation', 'user-invocable', 'allowed-tools', 'disallowed-tools', 'model', 'effort', 'context', 'agent', 'background', 'hooks', 'paths', 'shell', 'metadata', 'license', 'compatibility']);
export const AGENT_KEYS = new Set(['name', 'description', 'tools', 'disallowedTools', 'model', 'effort', 'color', 'maxTurns', 'skills', 'memory', 'background', 'isolation']);
export const AGENT_KEYS_IGNORED_IN_PLUGINS = new Set(['permissionMode', 'hooks', 'mcpServers', 'initialPrompt']);
export const SHIPPED_DIRS = ['skills', 'agents', 'kernel', 'modes', 'hooks'];
export const LIMITS = { auto: 300, manual: 120, agent: 150, autoTotal: 1500, autoPlusAgents: 2500 };
const KEBAB = /^[a-z0-9]+(-[a-z0-9]+)*$/;
const TRIGGER = /\buse (this )?when\b|\buse (before|after|during)\b/i;
const MACHINE_PATH = /(\/Users\/[A-Za-z]|\/home\/[a-z]|[A-Z]:\\Users\\|~\/Code\/)/;
const LONG_DASH = /[–—]/g;
const CURLY = /[‘’“”]/g;

export const rel = (model, p) => relative(model.root, p);

function walk(dir) {
  if (!existsSync(dir)) return [];
  const out = [];
  for (const name of readdirSync(dir)) {
    const p = join(dir, name);
    if (statSync(p).isDirectory()) out.push(...walk(p));
    else out.push(p);
  }
  return out;
}

export function loadModel(root) {
  const skills = [];
  const skillsDir = join(root, 'skills');
  if (existsSync(skillsDir)) {
    for (const dir of readdirSync(skillsDir)) {
      const file = join(skillsDir, dir, 'SKILL.md');
      if (!existsSync(file)) continue;
      const fm = parseFrontmatter(readFileSync(file, 'utf8'));
      skills.push({ name: fm.data.name, dir, file, data: fm.data, body: fm.body, error: fm.error });
    }
  }
  const kernelPath = join(root, 'kernel', 'kernel.md');
  const kernelText = existsSync(kernelPath) ? readFileSync(kernelPath, 'utf8') : '';
  const routed = new Set([...kernelText.matchAll(/Read \{KERN\}\/([a-z0-9-]+)\/SKILL\.md/g)].map((m) => m[1]));
  for (const s of skills) s.tier = s.data['disable-model-invocation'] !== 'true' ? 'auto' : routed.has(s.name) ? 'path' : 'slash';
  const cases = {};
  const casesDir = join(root, 'evals', 'cases');
  if (existsSync(casesDir)) {
    for (const f of readdirSync(casesDir).filter((n) => n.endsWith('.json'))) {
      try { cases[f.replace(/\.json$/, '')] = JSON.parse(readFileSync(join(casesDir, f), 'utf8')); }
      catch (e) { cases[f.replace(/\.json$/, '')] = { parseError: e.message }; }
    }
  }
  const agents = [];
  const agentsDir = join(root, 'agents');
  if (existsSync(agentsDir)) {
    for (const f of readdirSync(agentsDir).filter((n) => n.endsWith('.md'))) {
      const file = join(agentsDir, f);
      const fm = parseFrontmatter(readFileSync(file, 'utf8'));
      agents.push({ name: fm.data.name, base: f.replace(/\.md$/, ''), file, data: fm.data, body: fm.body, error: fm.error });
    }
  }
  const exFile = join(root, 'scripts', 'lint-exemptions.json');
  const exemptions = existsSync(exFile) ? JSON.parse(readFileSync(exFile, 'utf8')) : [];
  const shipped = SHIPPED_DIRS.flatMap((d) => walk(join(root, d)));
  return { root, skills, agents, exemptions, shipped, kernelText, cases };
}

export const err = (rule, path, message) => ({ rule, path, level: 'error', message });
export const warn = (rule, path, message) => ({ rule, path, level: 'warn', message });

export const RULES = [
  { id: 1, check(model) {
    const out = [];
    for (const s of model.skills) {
      const p = rel(model, s.file);
      if (s.error) { out.push(err(1, p, s.error)); continue; }
      if (!KEBAB.test(s.dir)) out.push(err(1, p, `directory ${s.dir} is not kebab case`));
      else if (s.name !== s.dir) out.push(err(1, p, `name ${s.name} does not equal directory ${s.dir}`));
    }
    for (const a of model.agents) {
      const p = rel(model, a.file);
      if (a.error) { out.push(err(1, p, a.error)); continue; }
      if (a.name !== a.base) out.push(err(1, p, `name ${a.name} does not equal file name ${a.base}`));
    }
    return out;
  } },
  { id: 2, check(model) {
    const out = [];
    for (const s of model.skills) {
      for (const k of Object.keys(s.data)) if (!SKILL_KEYS.has(k)) out.push(err(2, rel(model, s.file), `unknown frontmatter key ${k}`));
    }
    for (const a of model.agents) {
      for (const k of Object.keys(a.data)) {
        if (AGENT_KEYS_IGNORED_IN_PLUGINS.has(k)) out.push(err(2, rel(model, a.file), `${k} is ignored for plugin agents; use tools, disallowedTools and kern guards`));
        else if (!AGENT_KEYS.has(k)) out.push(err(2, rel(model, a.file), `unknown agent key ${k}`));
      }
    }
    return out;
  } },
  { id: 3, check(model) {
    const out = [];
    let autoTotal = 0;
    let agentTotal = 0;
    for (const s of model.skills) {
      if (s.error) continue;
      const d = s.data.description || '';
      const p = rel(model, s.file);
      if (!d) { out.push(err(3, p, 'description missing')); continue; }
      if (s.tier === 'auto') {
        autoTotal += d.length;
        if (d.length > LIMITS.auto) out.push(err(3, p, `auto description ${d.length} chars, limit ${LIMITS.auto}`));
        if (!TRIGGER.test(d)) out.push(err(3, p, 'auto description needs a trigger such as "Use when" or "Use before"'));
      } else if (d.length > LIMITS.manual) out.push(err(3, p, `description ${d.length} chars, limit ${LIMITS.manual}`));
    }
    for (const a of model.agents) {
      const d = a.data.description || '';
      agentTotal += d.length;
      if (d.length > LIMITS.agent) out.push(err(3, rel(model, a.file), `agent description ${d.length} chars, limit ${LIMITS.agent}`));
    }
    if (autoTotal > LIMITS.autoTotal) out.push(err(3, 'skills', `auto descriptions total ${autoTotal} chars, limit ${LIMITS.autoTotal}`));
    if (autoTotal + agentTotal > LIMITS.autoPlusAgents) out.push(err(3, 'skills', `auto plus agent descriptions total ${autoTotal + agentTotal} chars, limit ${LIMITS.autoPlusAgents}`));
    return out;
  } },
  { id: 4, check(model) {
    const out = [];
    for (const s of model.skills) {
      const p = rel(model, s.file);
      const local = [...s.body.matchAll(/`((?:references|templates|scripts|prompts)\/[\w./-]+)`|\]\(((?:references|templates|scripts|prompts)\/[\w./-]+)\)/g)].map((m) => m[1] || m[2]);
      for (const r of local) if (!existsSync(join(model.root, 'skills', s.dir, r))) out.push(err(4, p, `referenced file missing: ${r}`));
      const rooted = [...s.body.matchAll(/\$\{CLAUDE_PLUGIN_ROOT\}\/([\w./-]+)/g)].map((m) => m[1].replace(/[.,;:]+$/, ''));
      for (const r of rooted) if (!existsSync(join(model.root, r))) out.push(err(4, p, `referenced file missing: \${CLAUDE_PLUGIN_ROOT}/${r}`));
    }
    return out;
  } },
  { id: 8, check(model) {
    const out = [];
    const names = (process.env.KERN_LINT_NAMES || '').split(',').map((n) => n.trim()).filter(Boolean);
    for (const f of ['.lint-names', 'scripts/lint-names.txt']) {
      const namesFile = join(model.root, f);
      if (existsSync(namesFile)) names.push(...readFileSync(namesFile, 'utf8').split('\n').map((n) => n.trim()).filter((n) => n && !n.startsWith('#')));
    }
    const nameRes = names.map((n) => new RegExp(`\\b${n.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')}\\b`, 'i'));
    for (const f of model.shipped) {
      const text = readFileSync(f, 'utf8');
      const p = rel(model, f);
      if (MACHINE_PATH.test(text)) out.push(err(8, p, 'machine-specific path'));
      for (const re of nameRes) if (re.test(text)) out.push(err(8, p, `personal name matches ${re.source}`));
    }
    return out;
  } },
  { id: 10, check(model) {
    return model.exemptions.filter((e) => !e.reason || !String(e.reason).trim()).map((e) => err(10, 'scripts/lint-exemptions.json', `exemption for rule ${e.rule} on ${e.path} has no reason`));
  } },
  { id: 11, check(model) {
    const out = [];
    const files = [...model.shipped, join(model.root, 'README.md'), join(model.root, 'CHANGELOG.md')].filter((f) => existsSync(f) && /\.(md|sh|json|yml)$|\/hooks\/[a-z-]+$/.test(f));
    for (const f of files) {
      const text = readFileSync(f, 'utf8');
      const p = rel(model, f);
      if ((text.match(LONG_DASH) || []).length) out.push(err(11, p, 'long dash; use a period or a comma'));
      if ((text.match(CURLY) || []).length) out.push(err(11, p, 'curly quotes; use straight quotes'));
    }
    return out;
  } },
];

export function runLint(model) {
  const findings = RULES.flatMap((r) => r.check(model));
  const valid = model.exemptions.filter((e) => e.reason && String(e.reason).trim());
  return findings.filter((f) => f.rule === 10 || !valid.some((e) => e.rule === f.rule && e.path === f.path));
}
```

```js
#!/usr/bin/env node
// Lint rule 14: manifests and the newest CHANGELOG release agree; shipped changes add an Unreleased line.
// Idea from addyosmani/agent-skills scripts/validate-versions.js (MIT); the code is written for kern.
import { readFileSync } from 'node:fs';
import { join, resolve } from 'node:path';
import { execFileSync } from 'node:child_process';
import { fileURLToPath } from 'node:url';

const SHIPPED = /^(skills|agents|kernel|modes|hooks)\//;
const json = (root, p) => JSON.parse(readFileSync(join(root, p), 'utf8'));

export function unreleasedBullets(changelog) {
  const m = changelog.match(/^## \[Unreleased\]\n([\s\S]*?)(?=^## \[|(?![\s\S]))/m);
  return m ? m[1].split('\n').filter((l) => /^- /.test(l)) : [];
}

export function checkVersions(root) {
  const problems = [];
  const plugin = json(root, '.claude-plugin/plugin.json').version;
  const market = json(root, '.claude-plugin/marketplace.json').plugins?.[0]?.version;
  const changelog = readFileSync(join(root, 'CHANGELOG.md'), 'utf8');
  const release = changelog.match(/^## \[(\d+\.\d+\.\d+)\]/m)?.[1];
  if (plugin !== market) problems.push(`plugin.json ${plugin} != marketplace.json ${market}`);
  if (!release) problems.push(`CHANGELOG.md has no release heading; expected ## [${plugin}] - <date>`);
  else if (release !== plugin) problems.push(`newest CHANGELOG release ${release} != plugin.json ${plugin}`);
  return problems;
}

export function checkUnreleased(root, changedFiles) {
  if (!changedFiles.some((f) => SHIPPED.test(f))) return [];
  const changelog = readFileSync(join(root, 'CHANGELOG.md'), 'utf8');
  return unreleasedBullets(changelog).length ? [] : ['shipped files changed but ## [Unreleased] has no bullet'];
}

if (process.argv[1] && resolve(process.argv[1]) === fileURLToPath(import.meta.url)) {
  const root = fileURLToPath(new URL('..', import.meta.url));
  const problems = checkVersions(root);
  const i = process.argv.indexOf('--pr');
  if (i > 0) {
    const base = process.argv[i + 1];
    const changed = execFileSync('git', ['-C', root, 'diff', '--name-only', `${base}...HEAD`], { encoding: 'utf8' }).split('\n').filter(Boolean);
    problems.push(...checkUnreleased(root, changed));
  }
  for (const p of problems) console.log(`error: ${p}`);
  console.log(problems.length ? 'versions: FAILED' : 'versions: agree');
  process.exit(problems.length ? 1 : 0);
}
```

```js
#!/usr/bin/env node
// Bumps both manifests and the CHANGELOG. Prints the tag command; never commits, tags or pushes.
import { readFileSync, writeFileSync } from 'node:fs';
import { join, resolve } from 'node:path';
import { fileURLToPath } from 'node:url';

export function bump(version, part) {
  const [ma, mi, pa] = version.split('.').map(Number);
  if (part === 'major') return `${ma + 1}.0.0`;
  if (part === 'minor') return `${ma}.${mi + 1}.0`;
  if (part === 'patch') return `${ma}.${mi}.${pa + 1}`;
  throw new Error(`unknown part ${part}; use major, minor or patch`);
}

export function release(root, part, date) {
  const pluginPath = join(root, '.claude-plugin/plugin.json');
  const marketPath = join(root, '.claude-plugin/marketplace.json');
  const logPath = join(root, 'CHANGELOG.md');
  const plugin = JSON.parse(readFileSync(pluginPath, 'utf8'));
  const market = JSON.parse(readFileSync(marketPath, 'utf8'));
  const log = readFileSync(logPath, 'utf8');
  const block = (log.match(/^## \[Unreleased\]\n([\s\S]*?)(?=^## \[)/m)?.[1] || '').trim();
  if (!block) throw new Error('Unreleased is empty; add a line before releasing');
  const next = bump(plugin.version, part);
  plugin.version = next;
  market.plugins[0].version = next;
  const updated = log.replace(/^## \[Unreleased\]\n[\s\S]*?(?=^## \[)/m, () => `## [Unreleased]\n\n## [${next}] - ${date}\n\n${block}\n\n`);
  writeFileSync(pluginPath, JSON.stringify(plugin, null, 2) + '\n');
  writeFileSync(marketPath, JSON.stringify(market, null, 2) + '\n');
  writeFileSync(logPath, updated);
  return next;
}

if (process.argv[1] && resolve(process.argv[1]) === fileURLToPath(import.meta.url)) {
  const root = fileURLToPath(new URL('..', import.meta.url));
  const next = release(root, process.argv[2], new Date().toISOString().slice(0, 10));
  console.log(`released ${next}; review the diff, commit, then run: git tag v${next}`);
}
```

```js
// <lines 62-102 and 121-139 of .upstream/addy/scripts/run-evals.js go here unchanged except `function` becomes `export function` for tokenize, termFreq, vec, cosine>

export function buildCorpus(docs) {
  const map = new Map();
  for (const d of docs) {
    const nameTokens = tokenize(d.name.replace(/-/g, ' '));
    map.set(d.name, termFreq([...nameTokens, ...nameTokens, ...tokenize(d.text)]));
  }
  const df = new Map();
  for (const tf of map.values()) for (const term of tf.keys()) df.set(term, (df.get(term) || 0) + 1);
  const n = map.size;
  const idf = (term) => Math.log(1 + n / (1 + (df.get(term) || 0)));
  return { docs: map, idf };
}

export function rank(prompt, corpus) {
  const pv = vec(termFreq(tokenize(prompt)), corpus.idf);
  const scores = [];
  for (const [name, tf] of corpus.docs) scores.push({ name, score: cosine(pv, vec(tf, corpus.idf)) });
  scores.sort((a, b) => b.score - a.score);
  return scores;
}

export function similarity(a, b, corpus) {
  return cosine(vec(corpus.docs.get(a), corpus.idf), vec(corpus.docs.get(b), corpus.idf));
}
```

```js
#!/usr/bin/env node
// Tier 1 routing evals (design spec 11.1). Adapted from addyosmani/agent-skills scripts/run-evals.js (MIT), deterministic tier only.
import { readFileSync, writeFileSync, readdirSync, existsSync } from 'node:fs';
import { join } from 'node:path';
import { fileURLToPath } from 'node:url';
import { isMain } from './lib/is-main.mjs';
import { loadModel } from './lib/lint-rules.mjs';
import { buildCorpus, rank, similarity } from './lib/rank.mjs';

const MIN_POSITIVE = 3;
const MIN_NEGATIVE = 2;
const MIN_EVALS = 1;
const COLLISION_WARN = 0.5;
const COLLISION_ERROR = 0.75;

export function targets(root) {
  const skills = loadModel(root).skills.filter((s) => s.tier === 'auto' && s.data.description)
    .map((s) => ({ name: s.name, text: s.data.description, kind: 'skill' }));
  const dPath = join(root, 'evals', 'distractors.json');
  const distractors = existsSync(dPath) ? JSON.parse(readFileSync(dPath, 'utf8')).map((d) => ({ name: d.name, text: d.description, kind: 'distractor' })) : [];
  return [...skills, ...distractors];
}

function loadCases(root) {
  const dir = join(root, 'evals', 'cases');
  if (!existsSync(dir)) return [];
  return readdirSync(dir).filter((f) => f.endsWith('.json')).map((f) => {
    try { return { file: f, data: JSON.parse(readFileSync(join(dir, f), 'utf8')) }; }
    catch (e) { return { file: f, parseError: e.message }; }
  });
}

export function evaluate(root, { minRank1 }) {
  const all = targets(root);
  const owners = all.filter((t) => t.kind !== 'distractor');
  const corpus = buildCorpus(all);
  const names = new Set(all.map((t) => t.name));
  const cases = loadCases(root);
  const errors = [];
  const warnings = [];
  let positives = 0;
  let rank1 = 0;

  for (const t of owners) if (!cases.some((c) => c.file === `${t.name}.json`)) errors.push(`${t.name}: no eval case file (evals/cases/${t.name}.json)`);

  for (const c of cases) {
    if (c.parseError) { errors.push(`${c.file}: invalid JSON: ${c.parseError}`); continue; }
    const d = c.data;
    const expected = c.file.replace(/\.json$/, '');
    if (d.skill_name !== expected) errors.push(`${c.file}: skill_name "${d.skill_name}" does not match the file name`);
    if (!owners.some((t) => t.name === expected)) { errors.push(`${c.file}: no such auto skill or kernel row`); continue; }
    for (const ev of d.evals || []) {
      const ok = Number.isInteger(ev.id) && typeof ev.prompt === 'string' && typeof ev.expected_output === 'string' && Array.isArray(ev.expectations) && ev.expectations.length > 0;
      if (!ok) errors.push(`${c.file}: eval id=${ev.id} does not match the evals schema`);
      const kind = ev.kind || 'execution';
      if (!['execution', 'dialogue'].includes(kind)) errors.push(`${c.file}: eval id=${ev.id} has unknown kind "${kind}"`);
      if (kind === 'execution' && !(Array.isArray(ev.files) && ev.files.length)) errors.push(`${c.file}: eval id=${ev.id} needs files[]`);
      for (const f of ev.files || []) if (!existsSync(join(root, 'evals', 'fixtures', f))) errors.push(`${c.file}: eval id=${ev.id} fixture not found: evals/fixtures/${f}`);
    }
    for (const p of d.trigger?.positive || []) {
      positives++;
      const topK = p.top_k || 3;
      const r = rank(p.prompt, corpus);
      const idx = r.findIndex((x) => x.name === expected);
      const hit = r[idx];
      if (idx === 0 && hit.score > 0) rank1++;
      if (!hit || hit.score === 0) errors.push(`${expected}: description shares no vocabulary with "${p.prompt}"`);
      else if (idx >= topK) errors.push(`${expected}: positive prompt ranked #${idx + 1} (need top ${topK}): "${p.prompt}"; top: ${r.slice(0, 3).map((x) => `${x.name} ${x.score.toFixed(2)}`).join(', ')}`);
    }
    for (const n of d.trigger?.negative || []) {
      const r = rank(n.prompt, corpus);
      if (r[0].name === expected && r[0].score > 0) errors.push(`${expected}: ranked #1 for negative prompt "${n.prompt}"`);
      if (n.owner) {
        if (!names.has(n.owner)) errors.push(`${c.file}: negative names unknown owner "${n.owner}"`);
        else {
          const oi = r.findIndex((x) => x.name === n.owner);
          const si = r.findIndex((x) => x.name === expected);
          if (r[oi].score === 0 || oi > si) errors.push(`${expected}: owner ${n.owner} does not outrank it for "${n.prompt}"`);
        }
      }
    }
    const pc = (d.trigger?.positive || []).length;
    const nc = (d.trigger?.negative || []).length;
    const ec = (d.evals || []).length;
    if (pc < MIN_POSITIVE || nc < MIN_NEGATIVE || ec < MIN_EVALS) errors.push(`${expected}: below required minimums (${pc}/${nc}/${ec}; need ${MIN_POSITIVE}/${MIN_NEGATIVE}/${MIN_EVALS})`);
  }

  // targets() puts owners first and distractors last, so all[i] === owners[i] for i < owners.length.
  for (let i = 0; i < owners.length; i++) {
    for (let j = i + 1; j < all.length; j++) {
      const a = owners[i].name;
      const b = all[j].name;
      const sim = similarity(a, b, corpus);
      if (sim >= COLLISION_ERROR) errors.push(`collision: ${a} and ${b} are ${(sim * 100).toFixed(0)}% similar`);
      else if (sim >= COLLISION_WARN) warnings.push(`overlap: ${a} and ${b} are ${(sim * 100).toFixed(0)}% similar`);
    }
  }

  const rank1Rate = positives ? Math.floor((rank1 / positives) * 100) : null;
  if (minRank1 !== null && rank1Rate !== null && rank1Rate < minRank1) errors.push(`rank-1 rate ${rank1Rate}% is below the baseline ${minRank1}%`);
  return { errors, warnings, rank1Rate };
}

if (isMain(import.meta.url)) {
  const root = fileURLToPath(new URL('..', import.meta.url));
  const basePath = join(root, 'evals', 'baseline.json');
  const baseline = JSON.parse(readFileSync(basePath, 'utf8'));
  const r = evaluate(root, { minRank1: baseline.min_rank1 });
  for (const w of r.warnings) console.log(`warn: ${w}`);
  for (const e of r.errors) console.log(`error: ${e}`);
  console.log(`rank-1 rate: ${r.rank1Rate ?? 'n/a'}% (baseline ${baseline.min_rank1}%)`);
  if (process.argv.includes('--update-baseline') && !r.errors.length && r.rank1Rate !== null && r.rank1Rate > baseline.min_rank1) {
    writeFileSync(basePath, JSON.stringify({ min_rank1: r.rank1Rate }, null, 2) + '\n');
    console.log(`baseline raised to ${r.rank1Rate}%`);
  }
  console.log(r.errors.length ? 'route-eval: FAILED' : 'route-eval: passed');
  process.exit(r.errors.length ? 1 : 0);
}
```
