# kern M2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship kern's first working workflow: worktree and snapshot scripts, the check scripts behind G7, G9 and G10, guard G18, the three M2 agents, the eleven M2 skills with their kernel routes and evals, a kernel-adherence grader, and a pilot on two real projects.

**Architecture:** Work happens in kern-made git worktrees off a freshly fetched `origin/<base>`; per-task review needs no commits because `wt-snap` turns a worktree's state into a tree id through a temporary index and `wt-diff` builds review packages between two tree ids. Skills are markdown files reached through kernel rows (path tier), slash commands, or descriptions (auto tier), and they call bash scripts in `scripts/` by absolute path. Agents are read-only except the implementer, which works in one worktree and never commits.

**Tech Stack:** bash 3.2+ and POSIX tools, git 2.31+ (`rev-parse --path-format`, `worktree add --no-track`), bats-core, shellcheck, Node 22 (`node:test`, no npm dependencies), Claude Code 2.1.296 (`claude -p --plugin-dir`, `--output-format stream-json`).

**Spec:** `docs/specs/2026-10-12-kern-design.md` (sections 3, 4.3, 5, 8, 9, 13, 14) and `docs/specs/2026-10-12-kern-m1-m2-skills.md` (sections A, C, D, E). Shared names, signatures and exit codes: `docs/plans/contract.md`, including its sections "Additions from the M2 plan" and "M0 as written (binding)". Executors read the spec, the contract and this plan.

## Global Constraints

- Plugin name `kern`; skills invoked as `/kern:<skill>`; plugin agents appear as `kern:<name>`.
- Description limits: auto skills at most 300 chars with a trigger phrase; path and slash skills at most 120 chars; agents at most 150 chars; auto skills plus agents at most 2,500 chars. M2 total: prove-it 257 + recall 265 + implementer 149 + task-reviewer 144 + investigator 130 = 945.
- A frontmatter `description` that contains `: ` is double-quoted (or single-quoted when it holds double quotes), because Claude Code parses frontmatter as YAML; the parsed text is the spec's text.
- Path-tier bodies use no `$ARGUMENTS` placeholders and no `!` command injection. Skill files write `${CLAUDE_PLUGIN_ROOT}/...` for every path into kern; the kernel header prints the absolute root for skills reached by Read.
- A repo-level script is always written as `${CLAUDE_PLUGIN_ROOT}/scripts/<name>` and run as `bash ${CLAUDE_PLUGIN_ROOT}/scripts/<name>`, so a guard sees the script call and lint rule 4 resolves it. A backticked `scripts/...`, `references/...` or `templates/...` path inside a skill means that skill's own directory.
- `MAIN` is the main worktree root (first `worktree` line of `git worktree list --porcelain`); `WORK` is `MAIN/<work_dir>`, default `.kern`; settings and working files resolve from `MAIN`, never from cwd.
- Defaults that skills state when they apply: D1 no commits unless asked; D2 no push, PR, tracker write, deploy or external write without approval; D3 never checkout, switch, reset --hard, stash, bisect or clean in the main checkout, and no two writers share a worktree at once; D4 tasks sharing files or a local service run one at a time; D5 judgment calls go to the user; D6 no silent fallbacks, a missing setting is asked for; D7 stored shapes change by expand and contract; D8 production and declared read-only systems stay read-only; D9 touching a file outside the approved plan pauses; D10 fix loops stop after 3 rounds with a split proposal; D11 new behaviour ships with tests; D12 secrets are never printed.
- Floor actions never loosen: merge, production deploy, data deletion, force-push to a shared branch, messaging people.
- Approval: only an explicit yes. "Sounds good", "whatever you think" and silence are not yes. Approval is recorded as `status: approved` with the date and the user's words in the spec or plan file.
- Step 0 of every M2 skill, verbatim: `0. Defer: if the kern settings block names an override for this job, follow that project skill instead, say so in one line, and stop.`
- Todo idiom: every route file's first H2 is `## Steps`; the kernel copies the steps verbatim into the todo list; a step not done stays as `skip: <reason>`.
- Autopilot as skills see it: on only when no settings layer says `autopilot: denied` and the hook-injected line reads `autopilot=on`; anything that would ask is denied; judgment calls are parked as `parked: <question>; default: <choice>; why: <one line>` ledger lines; merge, deploy, review posting and tracker writes stay human.
- Visual pages ship in M4. A step that says "page when installed" checks `${CLAUDE_PLUGIN_ROOT}/skills/visual/SKILL.md`; absent, it stays in chat and says once "visual pages not installed".
- Model table: implementer `haiku` for batched mechanical edits, `sonnet` by default, `opus` for cross-module work or a round-3 fix; task reviewer `sonnet`; final review `opus`; investigator `sonnet`; transcript miners `haiku`; `model.<role>` overrides; every dispatch names its model.
- Port-task convention: a prose file ported from an upstream source names the source file and line range under `.upstream/<source>/`, lists the required headings in order, states the adaptation rules (no source tags, no personal names or machine paths, kern vocabulary such as `WORK`, `MAIN`, `kern:investigator` and settings keys, unslop rules, no long dashes or curly quotes), gives the full text of anything that is a contract, and ends with a check command: lint, a `grep` per required heading, and a size bound with `wc -c`.
- Upstream layout: `.upstream/superpowers/skills/...`, `.upstream/pstack/pstack/skills/...`, `.upstream/pocock/skills/engineering/...`, `.upstream/addy/skills/...`, `.upstream/local/recall/SKILL.md` (filled by `scripts/fetch-upstream`, M0).
- Every task that changes `skills/`, `agents/`, `kernel/` or `hooks/` adds one line under `## [Unreleased]` in `CHANGELOG.md` (lint rule 14).
- Commits: subject `M2: <imperative summary>`, 72 chars or fewer; body says why; no attribution trailers; stage named paths only (`git add -- <paths>`), never `-A`. Pushes happen only after the user says yes.
- Tests: bats-core 1.5+ (`run --separate-stderr`), run through `tests/run-bats`, which on macOS puts `/bin/bash` 3.2 first on PATH so scripts are tested on the bash they meet there. bash 3.2 ignores a false `[[ ]]` in the middle of a test, so every `[[ ]]` assertion ends with `|| false`; `tests/run-bats` refuses to run while any `.bats` file has a bare one. Scripts stay bash 3.2 compatible.
- Prose in every file follows unslop: answer first, no filler, no long dashes, no curly quotes.

## Review Focus

1. **A repo whose path contains a space** (`~/Code/my project`). Every script quotes its paths; a missing quote breaks worktree creation, snapshots and diffs only on such machines. Pinned in Task 1 (`wt-new works when the repo path has a space`) and Task 2 (`wt-snap and wt-diff work under a path with a space`).
2. **A task that deletes a tracked file and adds a binary file.** Snapshots, forks and patches must carry deletions and binary content, or integration silently drops them. Pinned in Task 2 (`snapshot drops a deleted tracked file`) and Task 3 (`fork carries a deletion and a binary file`, `wt-apply applies a binary patch`).
3. **A plan whose task text holds a fenced block with a `### Task 9` line.** `task-brief` must not start or stop a task inside a fence. Pinned in Task 4 (`a Task heading inside a fence is ignored`).
4. **Investigator commands with pipes, quotes and `2>/dev/null`.** G18 must split simple commands correctly, allow a stderr redirect to `/dev/null`, and still deny a real redirect. Pinned in Task 7 (`pipes and stderr to /dev/null stay allowed`, `a file redirect is denied`).
5. **A project with no `origin` remote.** `wt-new` must stop with a clear message instead of branching off a stale local commit. Pinned in Task 1 (`no origin remote exits 2 with a message`).

```bash
# shellcheck shell=bash
# shellcheck disable=SC2154  # MAIN is set by the sourcing script
# Shared by wt-new and wt-fork. Sourced, never run. Needs hooks/lib/settings.sh and MAIN.

# wt_dir: the directory kern worktrees live in (worktree.dir, default MAIN/.claude/worktrees).
wt_dir() {
  local d
  d=$(settings_get worktree.dir .claude/worktrees)
  case "$d" in /*) ;; *) d="$MAIN/$d" ;; esac
  printf '%s\n' "$d"
}

# wt_path_free PATH: exit 2 when PATH already exists.
wt_path_free() {
  if [ -e "$1" ]; then
    echo "wt: path exists: $1" >&2
    return 2
  fi
}

# wt_exclude_dir DIR: keep a worktree dir inside MAIN out of the main checkout's status.
# DIR must exist. Appends to the common git dir's info/exclude, which applies to every worktree.
wt_exclude_dir() {
  local dir=$1 rel common
  case "$dir" in "$MAIN"/*) rel=${dir#"$MAIN"/} ;; *) return 0 ;; esac
  if git -C "$MAIN" check-ignore -q "$rel" 2>/dev/null; then return 0; fi
  common=$(git -C "$MAIN" rev-parse --path-format=absolute --git-common-dir)
  mkdir -p "$common/info"
  if ! grep -qxF "/$rel/" "$common/info/exclude" 2>/dev/null; then
    printf '/%s/\n' "$rel" >> "$common/info/exclude"
    echo "kern: added /$rel/ to .git/info/exclude" >&2
  fi
}

# wt_include DST: copy untracked files that MAIN/.worktreeinclude names (gitignore syntax) into DST.
wt_include() {
  local dst=$1 f wtrel
  [ -f "$MAIN/.worktreeinclude" ] || return 0
  wtrel=$(wt_dir)
  wtrel=${wtrel#"$MAIN"/}
  git -C "$MAIN" ls-files --others --ignored --directory --exclude-from="$MAIN/.worktreeinclude" |
    while IFS= read -r f; do
      f=${f%/}
      case "$f" in "$wtrel"|"$wtrel"/*|.kern|.kern/*) continue ;; esac
      [ -e "$dst/$f" ] && continue
      mkdir -p "$dst/$(dirname "$f")"
      cp -R "$MAIN/$f" "$dst/$f"
    done
}

# wt_setup WT: run worktree.setup in WT and write the marker wt-check looks for.
wt_setup() {
  local wt=$1 setup gitdir
  gitdir=$(git -C "$wt" rev-parse --path-format=absolute --git-dir)
  if setup=$(settings_get worktree.setup); then
    if ! (cd "$wt" && bash -c "$setup") > "$gitdir/kern-setup.log" 2>&1; then
      echo "wt: worktree.setup failed in $wt (log: $gitdir/kern-setup.log)" >&2
      return 2
    fi
    printf 'setup: %s\n' "$setup" > "$gitdir/kern-setup-done"
  else
    printf 'setup: none (worktree.setup unset)\n' > "$gitdir/kern-setup-done"
    echo "wt: worktree.setup is unset; no setup ran in $wt" >&2
  fi
}
```

```bash
#!/usr/bin/env bash
# Create a kern worktree off a freshly fetched origin/<base>, copy .worktreeinclude files, run worktree.setup.
# Usage: wt-new SLUG [--detach] [--base REF] [--branch NAME]
# A SHA-shaped REF is used as a commit with no fetch (bisection); any other base must fetch from origin.
set -euo pipefail
here=$(cd "$(dirname "$0")" && pwd -P)
# shellcheck source=/dev/null
. "$here/../hooks/lib/settings.sh"
# shellcheck source=/dev/null
. "$here/lib/wt-common.sh"

usage() { echo "usage: wt-new SLUG [--detach] [--base REF] [--branch NAME]" >&2; exit 2; }
[ $# -ge 1 ] || usage
slug=$1
shift
case "$slug" in ''|.*|*[!A-Za-z0-9._-]*) echo "wt-new: bad slug: $slug" >&2; exit 2 ;; esac
detach=0 base='' branch=''
while [ $# -gt 0 ]; do
  case "$1" in
    --detach) detach=1; shift ;;
    --base) [ $# -ge 2 ] || usage; base=$2; shift 2 ;;
    --branch) [ $# -ge 2 ] || usage; branch=$2; shift 2 ;;
    *) usage ;;
  esac
done

MAIN=$(kern_main_root "$PWD") || { echo "wt-new: not a git repository" >&2; exit 2; }
if [ -z "$base" ]; then
  if ! base=$(settings_get base_branch); then
    base=$(bash "$here/kern-detect" base_branch | cut -f1) ||

```bash
#!/usr/bin/env bash
# Review package between two snapshot trees of a worktree. Also writes <package>.patch (binary-safe) for wt-apply.
# Usage: wt-diff WT FROM_TREE [TO_TREE] [--out FILE]
# Prints: package path, TO_TREE, then one changed path per line. Exit 3 when the trees are identical.
# Adapted from superpowers subagent-driven-development/scripts/review-package (MIT).
set -euo pipefail
here=$(cd "$(dirname "$0")" && pwd -P)
usage() { echo "usage: wt-diff WT FROM_TREE [TO_TREE] [--out FILE]" >&2; exit 2; }
[ $# -ge 2 ] || usage
wt=$1 from=$2
shift 2
to='' out=''
while [ $# -gt 0 ]; do
  case "$1" in
    --out) [ $# -ge 2 ] || usage; out=$2; shift 2 ;;
    -*) usage ;;
    *) [ -z "$to" ] || usage; to=$1; shift ;;
  esac
done
git -C "$wt" rev-parse --git-dir > /dev/null 2>&1 || { echo "wt-diff: not a git worktree: $wt" >&2; exit 2; }
[ -n "$to" ] || to=$(bash "$here/wt-snap" "$wt")
fromt=$(git -C "$wt" rev-parse --verify --quiet "$from^{tree}") || { echo "wt-diff: not a tree: $from" >&2; exit 2; }
tot=$(git -C "$wt" rev-parse --verify --quiet "$to^{tree}") || { echo "wt-diff: not a tree: $to" >&2; exit 2; }
if git -C "$wt" diff --quiet "$fromt" "$tot"; then
  echo "wt-diff: empty diff ${fromt:0:7}..${tot:0:7}" >&2
  exit 3
fi
if [ -z "$out" ]; then
  rdir=$(cd "$wt" && bash "$here/kern-dir" reviews)
  out="$rdir/${fromt:0:7}..${tot:0:7}.diff"
fi
mkdir -p "$(dirname "$out")"
{
  echo "# Review package: ${fromt:0:12}..${tot:0:12}"
  echo
  echo "## Files changed"
  git -C "$wt" diff --name-status "$fromt" "$tot"
  echo
  echo "## Stat"
  git -C "$wt" diff --stat "$fromt" "$tot"
  echo
  echo "## Diff"
  git -C "$wt" diff -U10 "$fromt" "$tot"
} > "$out"
git -C "$wt" diff --binary "$fromt" "$tot" > "$out.patch"
printf '%s\n%s\n' "$out" "$tot"
git -C "$wt" diff --name-only "$fromt" "$tot"
```

```bash
#!/usr/bin/env bash
# G7 as a script: list moves in a unified diff that lower the bar (suppressions, skipped or deleted tests,
# removed assertions, stubs and empty catch blocks, debug prints). Advisory: exit 1 on any hit.
# Usage: floor-scan DIFF_FILE    Output: path:line<TAB>class<TAB>text
# Patterns adapted from addyosmani/agent-skills constraint-driven-development/references/floor-guard.md (MIT).
set -euo pipefail
[ $# -eq 1 ] || { echo "usage: floor-scan DIFF_FILE" >&2; exit 2; }
[ -r "$1" ] || { echo "floor-scan: cannot read $1" >&2; exit 2; }
awk '
function is_test(p) {
  return p ~ /(^|\/)(test|tests|__tests__|spec|specs)\// || p ~ /[._-](test|spec)\.[A-Za-z0-9]+$/ || p ~ /_test\.go$/ || p ~ /(^|\/)test_[^\/]*\.py$/
}
function is_doc(p) { return p ~ /\.(md|mdx|txt|rst|adoc)$/ }
function hit(p, ln, cls, txt) {
  sub(/^[ \t]+/, "", txt)
  if (length(txt) > 120) txt = substr(txt, 1, 120)
  printf "%s:%d\t%s\t%s\n", p, ln, cls, txt
  hits++
}
function check_added(p, ln, t) {
  if (t ~ /@ts-ignore|@ts-nocheck|@ts-expect-error|eslint-disable|biome-ignore|#[ ]*noqa|#[ ]*type:[ ]*ignore|istanbul ignore|c8 ignore|nosemgrep|gitleaks:allow|Stryker disable|@SuppressWarnings|\/\/[ ]*nolint|pylint:[ ]*disable|rubocop:disable|#\[allow\(/) hit(p, ln, "silenced-checker", t)
  if (t ~ /\.(skip|todo)[(.]|(^|[^A-Za-z0-9_.])(xit|xdescribe|xtest|fit|fdescribe)\(|\.only\(|@pytest\.mark\.(skip|xfail)|t\.Skip\(|@Disabled|@Ignore/) hit(p, ln, "test-made-easier", t)
  if (is_doc(p)) return
  if (t ~ /catch[ ]*(\([^)]*\))?[ ]*\{[ ]*\}|except[^:]*:[ ]*pass[ ]*$|(^|[^A-Za-z])(TODO|FIXME)([^A-Za-z]|$)|[Nn]ot implemented|unimplemented!\(|todo!\(/) hit(p, ln, "unfinished-work", t)
  if (t ~ /console\.(log|debug|trace)\(|(^|[^A-Za-z0-9_.])debugger([^A-Za-z0-9_]|$)|(^|[^A-Za-z0-9_.])print\(|fmt\.Print(ln|f)?\(|binding\.pry|byebug|var_dump\(|dbg!\(|\[kern-dbg\]/) hit(p, ln, "debug-print", t)
}
/^diff --git / { inhunk = 0; file = ""; old = ""; deleted = 0; next }
!inhunk && /^deleted file mode/ { deleted = 1; next }
!inhunk && /^--- / { old = substr($0, 5); sub(/^a\//, "", old); next }
!inhunk && /^\+\+\+ / {
  file = substr($0, 5); sub(/^b\//, "", file)
  if (file == "/dev/null") { file = old; if (is_test(file)) hit(file, 0, "test-deleted", "file deleted") }
  next
}
/^@@ / {
  inhunk = 1
  split($0, a, " "); o = a[2]; nw = a[3]
  sub(/^-/, "", o); sub(/,.*/, "", o); sub(/^\+/, "", nw); sub(/,.*/, "", nw)
  oldln = o + 0; newln = nw + 0
  next
}
!inhunk { next }
/^\\/ { next }
/^\+/ { check_added(file, newln, substr($0, 2)); newln++; next }
/^-/ {
  t = substr($0, 2)
  if (is_test(file) && !deleted && t ~ /(^|[^A-Za-z_])(expect|assert|should)([^A-Za-z_]|$)/) hit(file, oldln, "assertion-removed", t)
  oldln++
  next
}
{ oldln++; newln++ }
END { exit (hits > 0) ? 1 : 0 }
' "$1"

# G9: in a diff's added lines, list commit ids the repo does not know and absolute words in added comments.
# Usage: claim-check WT DIFF_FILE    Output: path:line<TAB>sha-unknown|absolute-claim<TAB>value. Exit 1 on hits.

[ $# -eq 2 ] || { echo "usage: claim-check WT DIFF_FILE" >&2; exit 2; }
wt=$1 diff=$2
git -C "$wt" rev-parse --git-dir > /dev/null 2>&1 || { echo "claim-check: not a git worktree: $wt" >&2; exit 2; }
[ -r "$diff" ] || { echo "claim-check: cannot read $diff" >&2; exit 2; }

candidates() {
  awk '
  /^diff --git / { inhunk = 0; next }
  !inhunk && /^\+\+\+ / { file = substr($0, 5); sub(/^b\//, "", file); next }
  /^@@ / { inhunk = 1; split($0, a, " "); nw = a[3]; sub(/^\+/, "", nw); sub(/,.*/, "", nw); newln = nw + 0; next }
  !inhunk { next }
  /^\+/ {
    t = substr($0, 2)
    if (file !~ /(\.lock|lock\.json|lock\.yaml|\.sum|\.min\.[a-z]+|\.svg|\.snap)$/) {
      s = t; consumed = 0
      while (match(s, /[0-9a-f][0-9a-f][0-9a-f][0-9a-f][0-9a-f][0-9a-f][0-9a-f]+/)) {
        tok = substr(s, RSTART, RLENGTH)
        pre = (RSTART > 1) ? substr(s, RSTART - 1, 1) : ""
        pre2 = (RSTART > 2) ? substr(s, RSTART - 2, 2) : ""
        post = substr(s, RSTART + RLENGTH, 1)
        if (RLENGTH <= 40 && tok ~ /[0-9]/ && tok ~ /[a-f]/ && pre !~ /[A-Za-z0-9#_-]/ && post !~ /[A-Za-z0-9_-]/ && pre2 != "0x")
          print file "\t" newln "\tsha\t" tok
        s = substr(s, RSTART + RLENGTH)
      }

    c = t; sub(/^[ \t]+/, "", c)
    if (c ~ /^(\/\/|#|\/\*|\*|--|<!--|;)/) {
      lc = tolower(c)
      if (lc ~ /(^|[^a-z])(always|never|guaranteed|guarantees|impossible|cannot happen|can.t happen|no other|nothing else|only (caller|writer|place|path|way)|all (callers|writers|paths))([^a-z]|$)/) {

        print file "\t" newln "\tword\t" c
      }
    }

      ;;
    word)
      printf '%s:%s\tabsolute-claim\t%s\n' "$p" "$ln" "$val"
      hits=$((hits + 1))
      ;;
  esac
done < <(candidates)
if [ "$hits" -gt 0 ]; then exit 1; fi
exit 0

# shellcheck shell=bash
# shellcheck disable=SC2154  # TOOL and AGENT are set by hooks/pre-tool-use
# G18: kern's read-only agents may run only allowlisted read commands in Bash.
# Sourced by hooks/pre-tool-use, which sets TOOL, AGENT and KERN_INPUT and provides json_get, git_words, git_sub, vote.
G18_AGENTS="kern:investigator"

# g18_allowed SIMPLE_COMMAND: exit 0 when the command only reads.
g18_allowed() {
  local c w1 sub
  c=$(printf '%s' "$1" | sed -e 's/[0-9]*>&[0-9]//g' -e 's#[0-9]*>[[:space:]]*/dev/null##g' -e 's/^[[:space:]]*//')
  case "$c" in *'>'*|*'<('*|*'$('*|*'`'*) return 1 ;; esac
  w1=${c%%[[:space:]]*}
  case "$w1" in
    git)
      sub=$(git_sub "$c" | cut -f2) || return 1
      case "$sub" in
        log|show|blame|diff|grep|ls-files|ls-tree|rev-parse|rev-list|cat-file|merge-base|describe|shortlog|name-rev) ;;
        *) return 1 ;;
      esac
      case "$c" in *--output*|*--ext-diff*) return 1 ;; esac
      ;;
    rg)
      case "$c" in *--pre*) return 1 ;; esac
      ;;
    grep|ls|cat|head|tail|wc|uniq|cut|tr|nl|stat|file|du|pwd|echo|printf|basename|dirname|realpath|cd|true|test|jq|column|cmp|diff|comm) ;;
    sort)
      case "$c" in *' -o'*|*--output*) return 1 ;; esac
      ;;
    find)
      case "$c" in *' -delete'*|*' -exec'*|*' -execdir'*|*' -ok'*|*' -fprint'*|*' -fls'*) return 1 ;; esac
      ;;
    sed)
      case "$c" in *' -i'*|*--in-place*) return 1 ;; esac
      case "$c" in 'sed -n '*|'sed -En '*|'sed -nE '*|'sed -E -n '*) ;; *) return 1 ;; esac
      ;;
    *) return 1 ;;
  esac
  return 0
}

guard_g18() {
  [ "$TOOL" = "Bash" ] || return 0
  [ -n "${AGENT:-}" ] || return 0
  case " $G18_AGENTS " in *" $AGENT "*) ;; *) return 0 ;; esac
  local cmd line
  if ! cmd=$(json_get command); then
    vote deny g18 "read-only agent: the Bash input has no command"
    return 0
  fi
  while IFS= read -r line; do
    [ -n "$line" ] || continue
    if ! g18_allowed "$line"; then
      vote deny g18 "$AGENT is read-only; '${line%%[[:space:]]*}' with these arguments is not on its allowlist (git log, show, blame, diff, grep, ls-files; rg, grep, ls, cat, head, tail, wc; find without -exec or -delete; sed -n). Ask the controller to run it."
      return 0
    fi
  done <<EOF
$(git_words "$cmd")
EOF
}

// tests/helpers/md.mjs
// Helpers for tests that pin skill and agent files to their contracts.
import { readFileSync, existsSync, statSync } from 'node:fs';
import { join, dirname } from 'node:path';
import { fileURLToPath } from 'node:url';
import assert from 'node:assert/strict';
import { parseFrontmatter } from '../../scripts/lib/frontmatter.mjs';

export const ROOT = join(dirname(fileURLToPath(import.meta.url)), '..', '..');
export const DEFER = '0. Defer: if the kern settings block names an override for this job, follow that project skill instead, say so in one line, and stop.';

export function readDoc(rel) {
  const path = join(ROOT, rel);
  assert.ok(existsSync(path), `${rel} exists`);
  const raw = readFileSync(path, 'utf8');
  const { data, body, error } = raw.startsWith('---') ? parseFrontmatter(raw) : { data: {}, body: raw, error: null };
  return { path, raw, data, body, error };
}

export function stripFences(text) {
  let fence = false;
  return text.split('\n').map((l) => {
    if (/^\s{0,3}(```|~~~)/.test(l)) { fence = !fence; return ''; }
    return fence ? '' : l;
  }).join('\n');
}

export const h2s = (body) => stripFences(body).split('\n').filter((l) => /^## /.test(l)).map((l) => l.trim());

export function section(body, heading) {
  const lines = stripFences(body).split('\n');
  const i = lines.findIndex((l) => l.trim() === heading);
  if (i < 0) return null;
  const out = [];
  for (const l of lines.slice(i + 1)) { if (/^## /.test(l)) break; out.push(l); }
  return out.join('\n');
}

export const steps = (body) => (section(body, '## Steps') ?? '').split('\n').filter((l) => /^\d+\.\s/.test(l));

export function assertFrontmatter(rel, expected) {
  const d = readDoc(rel);
  assert.equal(d.error, null, `${rel} frontmatter parses`);
  assert.deepEqual(d.data, expected);
  return d;
}

export function assertHeadings(rel, headings) {
  const found = stripFences(readDoc(rel).raw).split('\n').filter((l) => /^#{1,3} /.test(l)).map((l) => l.trim());
  let at = -1;
  for (const h of headings) {
    const i = found.indexOf(h, at + 1);
    assert.ok(i > at, `${rel}: heading "${h}" missing or out of order; found ${JSON.stringify(found)}`);
    at = i;
  }
}

export function assertMaxBytes(rel, n) {
  const size = statSync(join(ROOT, rel)).size;
  assert.ok(size <= n, `${rel} is ${size} bytes; limit ${n}`);
}

export function assertContains(rel, needles) {
  const { raw } = readDoc(rel);
  for (const n of needles) assert.ok(raw.includes(n), `${rel} must contain: ${n}`);
}

```bash
#!/usr/bin/env bash
# Find the test file that creates an unwanted file or directory, by running test files one at a time.
# Usage: find-polluter.sh POLLUTION_PATH TEST_GLOB -- TEST_CMD...    (each test file is appended to TEST_CMD)
# Example: find-polluter.sh .git 'src/**/*.test.ts' -- npx vitest run
# Adapted from superpowers systematic-debugging/find-polluter.sh (MIT); the test command is an argument.
set -euo pipefail
if [ $# -lt 4 ] || [ "$3" != "--" ]; then
  echo "usage: find-polluter.sh POLLUTION_PATH TEST_GLOB -- TEST_CMD..." >&2
  exit 2
fi
pollution=$1
pattern=${2#./}
shift 3
files=$(find . \( -path "./$pattern" -o -path "./${pattern//\*\*\//}" \) -type f | sort -u)
[ -n "$files" ] || { echo "find-polluter: no test files match $pattern" >&2; exit 2; }
if [ -e "$pollution" ]; then
  echo "find-polluter: $pollution already exists; remove it first" >&2
  exit 2
fi
total=$(printf '%s\n' "$files" | wc -l | tr -d ' ')
n=0
while IFS= read -r f; do
  n=$((n + 1))
  echo "[$n/$total] $f"
  "$@" "$f" > /dev/null 2>&1 || true
  if [ -e "$pollution" ]; then
    echo "polluter: $f creates $pollution"
    exit 1
  fi
done <<EOF
$files
EOF
echo "no polluter found among $total test files"
```

# Human-in-the-loop reproduction loop. Copy this file, edit the steps between the markers, and run it.
# The agent runs the script; the user follows the prompts in their terminal.

# execute-plan

Turn an approved plan into verified, reviewed changes, with a record that survives compaction. Reached by the kernel row for executing an agreed plan, or typed as `/kern:execute-plan`.

Review needs no commits. Each task's change is the diff between two snapshot trees of its worktree: `tree-before` at dispatch and `tree-after` at return. A review verdict holds for that `tree-after` id only; any new tree voids it. Serial tasks share one plan worktree, one writer at a time; wave members each get a fork.

## Steps

0. Defer: if the kern settings block names an override for this job, follow that project skill instead, say so in one line, and stop.
1. Gate: the plan has `status: approved`, names its spec, and has `execution:` set or the mode was typed. No approval: stop. Record the main checkout's branch and a hash of its status (`git status --porcelain | git hash-object --stdin`).
2. Open the ledger: `bash ${CLAUDE_PLUGIN_ROOT}/scripts/kern-dir ledgers/<plan-slug>` gives the folder; `ledger.md` starts with `# kern ledger: <plan path>`. If it exists, tasks with a `Task N: complete` line are done; resume at the first task without one; a task whose last line is a fix round resumes that loop. After compaction, trust the ledger and the worktree over memory. Line formats: `references/ledger-format.md`.
3. Read the plan and the spec once and make one todo per task. Write a pre-flight table in the ledger: one row per pair of tasks sharing a file or an interface, one self-consistency row per task. A mechanical conflict gets a `Decision:` line. A spec or scope conflict: stop and ask before Task 1.
4. Build the overlap matrix from each task's Files plus `shared_services`. Disjoint tasks on the same frontier may run as one wave through `${CLAUDE_PLUGIN_ROOT}/skills/parallel-work/SKILL.md`; the rest run serially.
5. Create the plan worktree with `bash ${CLAUDE_PLUGIN_ROOT}/scripts/wt-new <plan-slug> --branch <name from branch.pattern>`, off a freshly fetched `origin/<base>`; `worktree.setup` runs inside it. Record its starting tree as a `Worktree:` ledger line. Run the baseline `test.full` there; a red baseline goes to the user.
6. Per task, take `tree-before` with `bash ${CLAUDE_PLUGIN_ROOT}/scripts/wt-snap <wt>` and run `bash ${CLAUDE_PLUGIN_ROOT}/scripts/task-start <ledger> <N> <tree-before>`. Then by mode:
   - `step`: do this one task by following `${CLAUDE_PLUGIN_ROOT}/skills/implement/SKILL.md`, report, and stop.
   - `inline`: do each task yourself with implement in the plan worktree, using absolute paths and `git -C`.
   - `delegate`: write the brief with `bash ${CLAUDE_PLUGIN_ROOT}/scripts/task-brief <plan> <N> <ledger dir>`, then dispatch `kern:implementer` with an explicit model (`references/model-selection.md`), the brief path, the worktree path, the base ref, the upstream Interfaces, the rulings from step 3, the report path `<ledger dir>/reports/task-N.md`, the absolute path of the implement SKILL.md, and the standing orders from `${CLAUDE_PLUGIN_ROOT}/skills/parallel-work/references/brief-template.md`. Pass no `isolation` parameter; kern made the worktree.
7. Handle the status line. DONE goes to review. DONE_WITH_CONCERNS: read the concerns, then review. NEEDS_CONTEXT: answer from the plan or spec, else ask the user. BLOCKED: split the task, add context, or go one model tier up. Never re-dispatch unchanged.
8. Review: take `tree-after` with `wt-snap`, then build the package with `bash ${CLAUDE_PLUGIN_ROOT}/scripts/wt-diff <wt> <tree-before> <tree-after> --out <ledger dir>/reviews/task-N-<tree7>.diff`. A changed file outside the task's Files pauses the run. Dispatch `kern:task-reviewer` in mode `task` with the brief, the report, the package, the plan's Global Constraints and the `review.rules` paths. Resolve every "cannot verify" item yourself. Do not pre-judge findings in the prompt.
9. Fix loop: rounds 1 and 2 resume the implementer with the findings; round 3 dispatches a fresh implementer one tier up; each round gets a `re-review` scoped to its own fix diff. Still open after round 3, or a round finds a bug in an earlier round's code: stop and escalate with a split proposal.
10. Close the task from the worktree: `bash ${CLAUDE_PLUGIN_ROOT}/scripts/task-done <ledger> <N> <tree-after> -- <task test command>`; it writes the complete line only on exit 0. Under autopilot only, commit the task's files with the checks of `/kern:commit` steps 3 to 6.
11. After a wave, apply each worker's patch into the plan worktree one at a time with `bash ${CLAUDE_PLUGIN_ROOT}/scripts/wt-apply <package>.patch <wt>`. A conflict stops the run. Then run `test.full` in the plan worktree.
12. Final review: package the whole change from the `Worktree:` starting tree to a fresh snapshot with `wt-diff`; dispatch `kern:task-reviewer` in mode `whole-branch` on `model.final_review`; re-grade findings by effect; make one fix pass, each fix red then green.
13. Finish: report decisions (with the cost if wrong), parked items, deferred minor findings, verification commands with their output, the worktree path and the branch. No commit, push or PR; offer `/kern:commit` and `/kern:finish-branch`. Assert the main checkout's branch and status hash are unchanged.
14. Propose teardown, do not run it: list the worktrees and their `git worktree remove` commands, and run them only on yes.

## Inputs

| Key | Default | Use |
|---|---|---|

## Outputs

`WORK/ledgers/<plan-slug>/` holding `ledger.md`, `briefs/`, `reports/`, `reviews/` and `logs/`. A plan worktree with uncommitted changes. A chat summary.

## Stops and autopilot

Worktree isolation, serialization, expand and contract, read-only production, fix-loop limits, tests and secrets rules stay as they are.

// Kernel routing rows: "| <when> | Read {KERN}/<skill>/SKILL.md |" or "| <when> | Read {ROOT}/kernel/<name>.md |".
export function kernelRows(kernelText) {
  const rows = [];
  for (const line of (kernelText || '').split(/\r?\n/)) {
    const m = line.match(/^\|\s*(.+?)\s*\|\s*(.+?)\s*\|\s*$/);
    if (!m) continue;
    const target = m[2].match(/\{KERN\}\/([a-z0-9-]+)\/SKILL\.md/) || m[2].match(/kernel\/([a-z0-9-]+)\.md/);
    if (target) rows.push({ when: m[1], route: target[1] });
  }
  return rows;
}

```js
// Grade a `claude -p --output-format stream-json` transcript for kernel adherence: the route's SKILL.md is read
// (or its auto skill invoked) before the first edit, and the first todo list holds the route's steps in order.
const EDITS = new Set(['Edit', 'Write', 'MultiEdit', 'NotebookEdit']);

export function readSteps(skillText) {
  const lines = skillText.split(/\r?\n/);
  const start = lines.findIndex((l) => l.trim() === '## Steps');
  if (start < 0) return [];
  const out = [];
  for (const l of lines.slice(start + 1)) {
    if (/^## /.test(l)) break;
    const m = l.match(/^\d+\.\s+(.*)$/);
    if (m) out.push(m[1]);
  }
  return out;
}

export const normalize = (s) => s.toLowerCase()
  .replace(/^\s*skip:\s*/, '')
  .replace(/^\s*\d+[.)]\s*/, '')
  .replace(/[`*_]/g, '')
  .replace(/\s+/g, ' ')
  .trim();

export function toolUses(events) {
  const out = [];
  for (const e of events) {
    if (e?.type !== 'assistant') continue;
    for (const c of e.message?.content ?? []) if (c?.type === 'tool_use') out.push({ name: c.name, input: c.input ?? {} });
  }
  return out;
}

export function grade(events, { route, steps }) {
  const uses = toolUses(events);
  const routed = uses.findIndex((u) =>
    (u.name === 'Read' && typeof u.input.file_path === 'string' && u.input.file_path.endsWith(`/skills/${route}/SKILL.md`)) ||
    (u.name === 'Skill' && [route, `kern:${route}`].includes(u.input.skill)));
  const firstEdit = uses.findIndex((u) => EDITS.has(u.name));
  const todo = uses.find((u) => u.name === 'TodoWrite');
  const items = todo
    ? (todo.input.todos ?? []).map((t) => t.content ?? '')
    : uses.filter((u, i) => u.name === 'TaskCreate' && (firstEdit === -1 || i < firstEdit)).map((u) => u.input.subject ?? '');
  const missing = [];
  steps.forEach((step, i) => {
    const item = items[i];
    const key = normalize(step).slice(0, 24);
    const ok = item !== undefined && (/^\s*skip:/i.test(item) || normalize(item).startsWith(key));
    if (!ok) missing.push(`step ${i}: "${step.slice(0, 60)}"`);
  });
  const reasons = [];
  if (routed === -1) reasons.push(`never read skills/${route}/SKILL.md`);
  else if (firstEdit !== -1 && firstEdit < routed) reasons.push(`read skills/${route}/SKILL.md only after the first edit`);
  if (!items.length) reasons.push('no todo list');
  else if (missing.length) reasons.push(`todo list does not hold the steps in order: ${missing.join('; ')}`);
  return { pass: reasons.length === 0, reasons, items };
}
```

#!/usr/bin/env node
// Opt-in behavioural check (design spec 11.1, tier 2): does a routed prompt make Claude read the route
// and copy its steps into the todo list? Costs tokens; never runs in default CI.
// Usage: node scripts/kernel-adherence.mjs [--case <id>] [--dry-run]
import { spawnSync, execFileSync } from 'node:child_process';
import { appendFileSync, cpSync, existsSync, mkdirSync, mkdtempSync, readFileSync, renameSync, rmSync, writeFileSync } from 'node:fs';
import { tmpdir } from 'node:os';
import { join } from 'node:path';
import { fileURLToPath } from 'node:url';
import { grade, readSteps } from './lib/adherence.mjs';

const ROOT = fileURLToPath(new URL('..', import.meta.url));
const MODEL = process.env.KERN_EVAL_MODEL || 'claude-sonnet-5-5';
const args = process.argv.slice(2);
const only = args.includes('--case') ? args[args.indexOf('--case') + 1] : null;
const dryRun = args.includes('--dry-run');

function workspace(fixture) {
  const dir = mkdtempSync(join(tmpdir(), 'kern-adherence-'));
  cpSync(join(ROOT, 'evals', 'adherence', 'fixtures', fixture), dir, { recursive: true });
  if (existsSync(join(dir, '_kern'))) renameSync(join(dir, '_kern'), join(dir, '.kern'));
  mkdirSync(join(dir, '.claude'), { recursive: true });
  writeFileSync(join(dir, '.claude', 'settings.local.json'), JSON.stringify({ enabledPlugins: { 'superpowers@claude-plugins-official': false } }, null, 2) + '\n');
  const git = (...a) => execFileSync('git', ['-C', dir, '-c', 'user.email=eval@example.com', '-c', 'user.name=eval', ...a], { stdio: 'ignore' });
  git('init', '--quiet', '--initial-branch=main');
  appendFileSync(join(dir, '.git', 'info', 'exclude'), '/.kern/\n/.claude/settings.local.json\n');
  git('add', '.');
  git('commit', '--quiet', '-m', 'fixture');
  return dir;
}

const cases = JSON.parse(readFileSync(join(ROOT, 'evals', 'adherence', 'cases.json'), 'utf8')).filter((c) => !only || c.id === only);
const results = [];
for (const c of cases) {
  const steps = readSteps(readFileSync(join(ROOT, 'skills', c.route, 'SKILL.md'), 'utf8'));
  const cmd = ['-p', c.prompt, '--plugin-dir', ROOT, '--output-format', 'stream-json', '--verbose', '--model', MODEL, '--max-turns', '8'];
  if (dryRun) {
    console.log(`${c.id}: claude ${cmd.map((a) => JSON.stringify(a)).join(' ')} (fixture ${c.fixture}, ${steps.length} steps)`);
    continue;
  }
  const cwd = workspace(c.fixture);
  const run = spawnSync('claude', cmd, { cwd, encoding: 'utf8', timeout: 10 * 60 * 1000, maxBuffer: 64 * 1024 * 1024 });
  const events = (run.stdout || '').split('\n').filter(Boolean).flatMap((l) => { try { return [JSON.parse(l)]; } catch { return []; } });
  const g = grade(events, { route: c.route, steps });
  results.push({ id: c.id, route: c.route, pass: g.pass, reasons: g.reasons, items: g.items, exit: run.status });
  console.log(`${g.pass ? 'PASS' : 'FAIL'} ${c.id} (${c.route})${g.pass ? '' : `: ${g.reasons.join('; ')}`}`);
  rmSync(cwd, { recursive: true, force: true });
}
if (!dryRun) {
  const version = execFileSync('claude', ['--version'], { encoding: 'utf8' }).trim();
  mkdirSync(join(ROOT, 'evals', 'results'), { recursive: true });
  const out = join(ROOT, 'evals', 'results', `adherence-${new Date().toISOString().replace(/[:.]/g, '-')}.json`);
  writeFileSync(out, JSON.stringify({ model: MODEL, claude: version, results }, null, 2) + '\n');
  console.log(`results: ${out}`);
  process.exit(results.length && results.every((r) => r.pass) ? 0 : 1);
}
