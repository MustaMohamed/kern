# recall chat

Catch the user up on this chat since their last message. Read-only.

## Scope

Assume the user remembers their last message and nothing after it. Notifications and subagent results are not the user's messages. Call each PR, branch or agent by a name they would know, not a label you coined during the work.

## Gather

Collect your own work, subagent reports and others' messages since that message. Check the live state of each PR, CI run and agent: say which are still running and which you could not check.

An action item is a decision or step only the user can take: a product choice, an approval, an irreversible action, access you lack. An item still waiting from before their last message counts. Work you can do yourself is not an action item; name it in one line.

## Reply

Open with one sentence giving the action-item count, or saying there are none. If nothing happened and nothing waits, say so and stop.

Then what happened, most important first: each result and what it means. Skip steps that changed nothing.

Then per action item: the decision, why now, the options with their cost, your recommendation, and what happens with no answer. If you do not know a part, say so instead of guessing. Link the detail when there is one, and write the summary so the user can decide without opening it.
