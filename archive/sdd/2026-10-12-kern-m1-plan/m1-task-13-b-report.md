## Part 2: design

- Bash flow: guard_g13 decodes the command with ti_get (also \u0000-\u007f). Prefilter: returns before settings_get unless the command, quotes and backslashes removed, holds ssh, scp, sftp, rsync, mysql, mariadb, psql, sqlite, sqlcmd or pg_ in any case. _g13_scan runs git_words; each record that names a client goes to one awk with the targets, a fed flag (_g13_fed: follows `|`/`|&` or cannot be found = fed), the whole command and the upstream record (_g13_upstream proves the record before the pipe). awk failure denies.
- awk qw() splits like sw(), marking unquoted redirects and words with run-time $ or backtick. A client is any word whose basename (lowercased, no .exe) is a client name, judged from that word on (paths, case, unknown wrappers, sshpass, xargs); _cmd_words' head too when no word matched (env -S). Deny reasons name the target and end "run it yourself with ! if it only reads".
- Targets: host any case, user@host, URLs; host:port matches -h/--host with -P/-p/--port (attached), URLs, conninfo host=/port=, PGHOST/PGPORT/MYSQL_HOST/MYSQL_TCP_PORT anywhere; localhost = 127.0.0.1 = ::1; no host = localhost, no port = client default; an option value naming a target as a whole host counts.
- ssh: options before and after the destination; deny with no remote command, input from a pipe or `<` (unless -n), or run-time text; exempt -N, -O, -G, -V, -W without command; -J/ProxyJump/HostName naming a target reach it; RemoteCommand judged; ProxyCommand/LocalCommand naming a target denies. Remote command split on ; & | newline ( ) { } backtick, quotes untrusted (cmd); redirects only to /dev/null, nul, $null or fd copies; each head on the closed read list; cmd /c|/k and powershell|pwsh -Command unwrapped with options. find -delete/-exec*/-ok*/-fprint*/-fls, date -s/--set/number, hostname NAME, file -C deny. ssh to a non-target: its remote command scanned as a command line, two levels (bastion).
- SQL: statements from -e, -c, -Q, --init-command and input files (-f, -i, <; ~ expanded; any extension); comments stripped, /*! is code; strings lexed every way the client may (mysql escapes on and off; psql E strings and everywhere). mysql \g \G allowed; psql \d* \l \x \q \g \gx \conninfo \timing; sqlite read-only dot set; sqlcmd GO, deny :cmd, !!, $(. Each statement starts with SELECT, SHOW, DESCRIBE, DESC, EXPLAIN or WITH (leading `(` allowed); deny on insert, update, delete, merge, drop, create, alter, grant, revoke, lock, unlock, into, outfile, dumpfile, FOR SHARE, side-effect functions (GET_LOCK, SLEEP, BENCHMARK, pg_terminate_backend, nextval, pg_advisory_*, dblink, lo_*, ...). SHOW skips create and set. sqlcmd also denies exec, kill, truncate anywhere. mysqldump denies without --single-transaction, and on -l/-x/-F, master-data, source-data, flush, delete-*-logs, dump-replica.
- Transfers: scp/rsync deny when the last positional is on a target; rsync long options without `=` both ways; rsync --remove-source-files, --del*, --rsync-path/-M with any operand on a target deny. sftp allows only the ruling's verbs, read from -b, a here-string, the only here-doc (quoted delimiter or no $), a `<` file, or a pipe from echo/printf/cat.
