What M1 ships

Six parts, all loaded by hooks rather than left to the model's memory

kernel/ · hooks/session-start

Kernel and routing

About 3,100 characters injected at session start and after /compact. A routing table sends prose work to technical-writing; project skills and rules outrank kern's own.

skills/mode · modes/terse.md

Modes and the terse voice

Voice and surface switch only from a typed command or a prompt-initial phrase. The terse voice now answers only what was asked.

skills/autopilot · G16

Autopilot grant

Only a typed /kern:autopilot on starts it. Every ask becomes a deny, merge and deploy stay human, and the skill states the exact commit, push and PR shapes that pass.

hooks/lib/settings.sh

Layered settings

Local, project and user files. Safety lists add up across layers, and a committed project file can tighten but never turn kern off or loosen a policy.

hooks/guards · 11 guards

Guards that enforce the rules

  • G00: under autopilot, denies commands kern cannot read
  • G1: git; proven push shape only, force pushes and main-checkout changes ask or deny
  • G2 to G4: draft PRs, review posting, untrusted text in bodies
  • G5, G6: commit convention and attribution, secret scans
  • G13: protected hosts are read-only (your V1 host)
  • G14, G15: tracker and chat writes, deploys and publishes
  • G16: kern state and settings, and Claude Code's own settings
skills/help · unslop · technical-writing

Help and writing

/kern:help maps kern and sets a project up without touching a tracked file. unslop and technical-writing are ported from your local copy and pstack.

Overall

How much each source serves kern's goals

1kern

Enforced human gates, a read-only model for protected hosts and project-first precedence, at about 3.1k standing characters.

2pstack

The most content: technical-writing, help, unslop's catalog and the steps idea. Cursor-native and autonomy-leaning ("i want everything merged" overnight).

3caveman

The voice and the hook design kern's prompt and subagent hooks follow. Needs node and costs about 9.4k standing characters.

4superpowers

The session-start delivery path and the subagent-driven process that built kern. No guards, and executing-plans commits unasked.

5addy

The eval harness kern's route-eval adapts, and specialist skills. Its safety is prose, and its skill listing alone is 9.3k characters.

6pocock

The one upstream guard, which a -C flag bypasses, and a confirm-before-write setup pattern.

Where a source does better

Worth taking into M2

pstack

ralph-loop enforces a stop condition and an iteration cap in a hook. kern's autopilot only asks for a stop predicate.

caveman

Token stats and a corpus-tested switch parser. kern's terse voice is checked by one live run.

addy

25 behavioural eval cases and an ADR shape. kern's M1 skills have text tests only.

superpowers

Ships a Windows hook runner. kern's CI runs Linux; bash 3.2 runs only in the Mac's ci-local.

kern

Kernel "ask first" items with no guard yet: a local rm, spend, permission changes outside settings files.

Accepted limits

What the guards knowingly do not catch

interpreters

Code in a script file, a python here-doc or a python -c one-liner. Shells are read; other languages are not.

aliases

Shell-snapshot aliases such as gpf!. M2 reads the snapshot and catches them.

config

GIT_CONFIG* environment settings, ssh config aliases and client config files that name a host.

size

Commands over about 40 KB reach the 20-second hook timeout and are blocked. M2 parses each command once.

deploys

Package scripts such as npm run deploy; kern cannot see what they run.
