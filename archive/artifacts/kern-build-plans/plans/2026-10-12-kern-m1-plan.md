# kern M1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship kern's kernel, mode switching, autopilot grant, settings layer, ten guards and the three M1 skills, all tested on macOS bash 3.2 and Linux bash 5.

**Architecture:** Four bash hooks (`session-start`, `subagent-start`, `prompt-submit`, `pre-tool-use`) share five sourced libraries under `hooks/lib/`. `session-start` renders `kernel/kernel.md` with the project settings summary; `prompt-submit` applies `/kern:mode` and `/kern:autopilot` and writes per-session state; `pre-tool-use` sources every `hooks/guards/g*.sh`, collects votes and prints the strictest. Skills are prose; `scripts/kern-*` give skills the same settings and repo facts the hooks use.

**Tech Stack:** bash 3.2+ and POSIX tools (awk, sed, grep, git), optional `gh` and `gitleaks`; bats-core for hook tests; Node 22 `node:test` for lint rules; shellcheck; Claude Code 2.1.296.

**Spec:** `docs/specs/2026-10-12-kern-design.md` (sections 4 to 8, 11.2, 14) and `docs/specs/2026-10-12-kern-m1-m2-skills.md` (sections A, B, E). Shared names: `docs/plans/contract.md`. M0 must be complete: this plan extends M0's `scripts/lib/lint-rules.mjs`, `tests/lint-rules.test.mjs`, `scripts/ci-local` and `.github/workflows/ci.yml`.

Every command runs from the repo root, `~/Code/projects/kern`, unless a step says otherwise.

## Global Constraints

- Kernel delivery: SessionStart target 4,000 chars (lint warning), lint error at 9,000, Claude Code's cap 10,000 per string. SubagentStart at most 1,200 chars.
- Kernel section budgets (design 4.2): header 100, precedence 420, routing 1,100, autonomy 650, evidence 330, context 125, reply 225, learning 160, paths 250, settings summary 600; total 3,960.
- M1 routing rows: technical-writing and context only. Every other row ships with its route (M2, M3, M6).
- Hooks use bash, POSIX tools and git only. `gh`, `jq` and `gitleaks` are used when present, never required. jq is never used, so behaviour does not change with it.
- Hooks are bash 3.2 compatible (macOS `/bin/bash`): no associative arrays, no `${var,,}`, no `mapfile`, no `;&`. A function that votes must never run in a pipeline subshell; loops read from here-documents instead.
- Plugin hooks use exec form: `"command": "bash", "args": ["${CLAUDE_PLUGIN_ROOT}/hooks/<name>"]`.
- PreToolUse decisions are `hookSpecificOutput.permissionDecision` (`allow`, `ask`, `deny`) with `permissionDecisionReason`. A hook that cannot parse its input returns `ask`, or `deny` under autopilot. It never allows on a parse failure. The dispatcher entry uses `"onFailure": "block"`.
- Policy keys: `commit.policy`, `push.policy`, `pr.policy`, `tracker.policy`, `review.post_policy`, each `ask` (default), `auto` or `deny`. Floor actions have no key and never loosen: merge, production deploy, data deletion, force-push to a shared branch, messaging people.
- Autopilot is on only when no settings layer says `autopilot: denied` and the session state says `autopilot: on`, which only the hook writes from a command the user typed.
- Session state: `${CLAUDE_PLUGIN_DATA}/sessions/<session_id>.state`, flat `key: value`, mode 0600, atomic write, symlinks refused. (Skills spec B1 wins over the design's `.json`.)
- `startup`, `clear` and `fork` reset the mode to settings defaults with autopilot off; `compact` and `resume` keep it.
- Settings and `.kern/` resolve from the main worktree root, the first `worktree` line of `git worktree list --porcelain`, never from the current directory.
- Description limits: path and slash skills at most 120 chars. A frontmatter value that contains `: ` is quoted, so YAML parsers read it.
- Shipped files (`skills/`, `agents/`, `kernel/`, `modes/`, `hooks/`): no machine paths, no personal names (lint rule 8), no long dashes or curly quotes (lint rule 11), and never the words caveman, ultracave or megacave as a name.
- `modes/terse.md` is written for kern. Caveman 3.2.0 (Apache-2.0) is credited in NOTICE as the source of the idea; no caveman text is copied.
- Commits: subject `M1: <imperative summary>`, 72 chars or fewer; body says why; no attribution trailers; `git add -- <paths>` only. Pushes happen only when the user says so.
- Port tasks follow the port-task convention in the M0 plan: source file and lines under `.upstream/<source>/`, required headings, adaptation rules, full text of every contract part, and a check command.

## Review Focus

1. **A git command hidden in a chain, a `$( )`, backticks or `bash -c '...'`.** The user expects G1 to see `cd x && git stash` and `bash -c 'git switch main'` the same as a bare command. Pinned: Task 10 test `a chained or substituted main-checkout command is still seen`; Task 9 `gitctx.bats` tests the splitter.
2. **A session running inside a linked worktree.** Settings, `.kern/` and the main-checkout test must resolve from the main worktree root, or a worktree session sees no settings and every guard misjudges "main checkout". Pinned: Task 3 test `a linked worktree reads the main checkout's untracked settings`; Task 4 test `kern-dir creates WORK/sub at the main root`; Task 10 test `the same commands in a linked worktree: no vote`.
3. **A prompt Claude Code starts itself that contains `/kern:autopilot on`:** a background subagent report, a cross-session message, a scheduled task, or a CronCreate Claude writes. None may switch autopilot on. Pinned: Task 8 test `wrapped prompts never switch`; Task 9 test `a scheduled prompt or relayed message carrying /kern:autopilot is denied`.
4. **A very large tool input, such as a 200 KB Write.** The guard dispatcher parses every Write; a quadratic parser would stall each one. Pinned: Task 2 test `a 200 KB value parses in under 5 seconds`.
5. **`gh` missing, offline or slow during the PR duplicate check.** The guard must not allow a PR it could not check, and must not hang the session. Pinned: Task 11 test `gh failing means dedup unknown`; Task 9 test `with_timeout returns promptly when the command finishes`.

```bash
# shellcheck shell=bash
# Shared bats helpers for kern hook and script tests.

# kern_root: absolute path of the kern repo (two levels above this file).
kern_root() {
  cd "$(dirname "${BASH_SOURCE[0]}")/../.." && pwd -P
}

# make_repo DIR: a git repo on main with user config, one commit (README.md), and a bare origin
# at DIR.origin with main pushed and refs/remotes/origin/HEAD set.
make_repo() {
  local dir="$1"
  git init -q -b main "$dir"
  git -C "$dir" config user.name "Test User"
  git -C "$dir" config user.email "test@example.com"
  git -C "$dir" config commit.gpgsign false
  printf 'readme\n' >"$dir/README.md"
  git -C "$dir" add README.md
  git -C "$dir" commit -q -m "init"
  git init -q --bare -b main "$dir.origin"
  git -C "$dir" remote add origin "$dir.origin"
  git -C "$dir" push -q origin main
  git -C "$dir" remote set-head origin main >/dev/null
}
```

```bash
# shellcheck shell=bash
# JSON helpers for kern hooks. POSIX awk only, so behaviour is the same with or without jq.
# All functions read the JSON document from $KERN_INPUT.

# Scanner shared by json_get and json_get_raw. Prints the value of the first object key equal to
# `key`. mode=str prints a decoded string value; mode=raw prints the raw JSON text of any value.
# Exit 0 found, 1 absent (or, in str mode, not a string), 2 malformed input.
_KERN_JSON_AWK='
function skip_ws(p) { while (p <= n && index(" \t\r\n", substr(buf, p, 1)) > 0) p++; return p }
function str_end(p,   d) {
  # p is the index just after an opening quote; returns the index of the closing quote, or 0.
  while (p <= n) {
    d = substr(buf, p, 1)
    if (d == "\\") { p += 2; continue }
    if (d == "\"") return p
    p++
  }
  return 0
}
function decode(s) {
  gsub(/\\\\/, "\001", s)
  gsub(/\\"/, "\"", s); gsub(/\\\//, "/", s)
  gsub(/\\n/, "\n", s); gsub(/\\t/, "\t", s); gsub(/\\r/, "\r", s)
  gsub(/\\b/, "\b", s); gsub(/\\f/, "\f", s)
  gsub(/\001/, "\\", s)
  return s
}
function raw_end(p,   c, depth, e) {
  c = substr(buf, p, 1)
  if (c == "\"") { e = str_end(p + 1); return e }
  if (c == "{" || c == "[") {
    depth = 0
    while (p <= n) {
      c = substr(buf, p, 1)
      if (c == "\"") { e = str_end(p + 1); if (!e) return 0; p = e + 1; continue }
      if (c == "{" || c == "[") depth++
      else if (c == "}" || c == "]") { depth--; if (depth == 0) return p }
      p++
    }
    return 0
  }
  while (p <= n && index(",}] \t\r\n", substr(buf, p, 1)) == 0) p++
  return p - 1
}
{ buf = buf (NR > 1 ? "\n" : "") $0 }
END {
  n = length(buf); i = 1
  while (i <= n) {
    c = substr(buf, i, 1)
    if (c != "\"") { i++; continue }
    e = str_end(i + 1)
    if (!e) exit 2
    tok = substr(buf, i + 1, e - i - 1)
    i = e + 1
    k = skip_ws(i)
    if (substr(buf, k, 1) != ":" || tok != key) continue
    k = skip_ws(k + 1)
    if (mode == "str") {
      if (substr(buf, k, 1) != "\"") exit 1
      e = str_end(k + 1)
      if (!e) exit 2
      printf "%s", decode(substr(buf, k + 1, e - k - 1))
      exit 0
    }
    e = raw_end(k)
    if (!e) exit 2
    printf "%s", substr(buf, k, e - k + 1)
    exit 0
  }
  exit 1
}'

# json_get KEY: decoded string value of the first "KEY": whose value is a string.
json_get() {
  printf '%s' "${KERN_INPUT-}" | LC_ALL=C awk -v key="$1" -v mode=str "$_KERN_JSON_AWK"
}

# json_get_raw KEY: raw JSON text of the first "KEY": value (object, array, string or literal).
json_get_raw() {
  printf '%s' "${KERN_INPUT-}" | LC_ALL=C awk -v key="$1" -v mode=raw "$_KERN_JSON_AWK"
}

# json_escape: stdin escaped for the body of a JSON string, without the surrounding quotes.
json_escape() {
  local tab cr
  tab=$(printf '\t'); cr=$(printf '\r')
  LC_ALL=C sed -e 's/\\/\\\\/g' -e 's/"/\\"/g' -e "s/${tab}/\\\\t/g" -e "s/${cr}/\\\\r/g" |
    LC_ALL=C awk 'BEGIN { sep = "" } { printf "%s%s", sep, $0; sep = "\\n" }'
}

# json_ok: exit 0 when $KERN_INPUT is one object: starts with { and ends with } after trimming.
json_ok() {
  local t
  t=$(printf '%s' "${KERN_INPUT-}" | tr -d ' \t\r\n')
  case "$t" in '{'*'}') return 0 ;; *) return 1 ;; esac
}

# ti_get KEY: json_get applied to the hook's tool_input object ($TOOL_INPUT, set by pre-tool-use).
ti_get() {
  KERN_INPUT="${TOOL_INPUT-}" json_get "$1"
}
```

```bash
# shellcheck shell=bash
# kern settings: layered flat `key: value` files resolved from the main worktree root.
# Needs KERN_ROOT (plugin root). Uses KERN_MAIN when set, else resolves it from CWD (or PWD).

# kern_main_root [dir]: the main worktree root (first `worktree` line of the porcelain list).
kern_main_root() {
  local dir="${1:-${CWD:-$PWD}}" line
  line=$(git -C "$dir" worktree list --porcelain 2>/dev/null | sed -n 's/^worktree //p' | head -n 1)
  [ -n "$line" ] || return 2
  printf '%s\n' "$line"
}

# _settings_files: the settings files in precedence order, one per line (existing or not).
_settings_files() {
  local main="${KERN_MAIN-}"
  if [ -z "$main" ]; then main=$(kern_main_root "${CWD:-$PWD}" 2>/dev/null) || main=""; fi
  if [ -n "$main" ]; then
    printf '%s\n' "$main/.claude/kern.local.yml" "$main/.claude/kern.yml"
  fi
  printf '%s\n' "$HOME/.claude/kern.yml"
}

# _settings_lookup FILE KEY: prints the value of KEY in FILE (last occurrence wins). Exit 1 absent.
_settings_lookup() {
  LC_ALL=C awk -v key="$2" -v sq="'" '
    {
      line = $0
      sub(/\r$/, "", line)
      if (line ~ /^[ \t]*#/ || line ~ /^[ \t]*$/) next
      p = index(line, ":")
      if (p == 0) next
      k = substr(line, 1, p - 1)
      gsub(/^[ \t]+|[ \t]+$/, "", k)
      if (k != key) next
      v = substr(line, p + 1)
      out = ""; q = ""; m = length(v)
      for (i = 1; i <= m; i++) {
        c = substr(v, i, 1)
        if (q == "" && (c == "\"" || c == sq)) q = c
        else if (q != "" && c == q) q = ""
        else if (q == "" && c == "#" && (i == 1 || substr(v, i - 1, 1) ~ /[ \t]/)) break
        out = out c
      }
      gsub(/^[ \t]+|[ \t]+$/, "", out)
      f = substr(out, 1, 1); l = substr(out, length(out), 1)
      if (length(out) >= 2 && f == l && (f == "\"" || f == sq)) out = substr(out, 2, length(out) - 2)
      val = out; found = 1
    }
    END { if (found) { print val; exit 0 } exit 1 }' "$1"
}

# settings_get KEY [DEFAULT]: prints the resolved value. Exit 0 found or defaulted, 3 unset.
settings_get() {
  local f v
  while IFS= read -r f; do
    [ -f "$f" ] || continue
    if v=$(_settings_lookup "$f" "$1"); then
      printf '%s\n' "$v"
      return 0
    fi
  done <<EOT
$(_settings_files)
EOT
  if [ $# -ge 2 ]; then
    printf '%s\n' "$2"
    return 0
  fi
  return 3
}

# settings_source KEY: prints the file that sets KEY, or `default`. Exit 0 always.
settings_source() {
  local f
  while IFS= read -r f; do
    [ -f "$f" ] || continue
    if _settings_lookup "$f" "$1" >/dev/null; then
      printf '%s\n' "$f"
      return 0
    fi
  done <<EOT
$(_settings_files)
EOT
  printf 'default\n'
}

# settings_keys FILE: every key set in FILE, one per line.
settings_keys() {
  LC_ALL=C awk '
    { line = $0; sub(/\r$/, "", line) }
    line ~ /^[ \t]*#/ || line ~ /^[ \t]*$/ { next }
    { p = index(line, ":"); if (p == 0) next
      k = substr(line, 1, p - 1); gsub(/^[ \t]+|[ \t]+$/, "", k); print k }' "$1" | sort -u
}

# settings_known_keys: the key column of kernel/settings.md, one per line. A `<...>` part is a wildcard.
settings_known_keys() {
  sed -n 's/^| `\([^`]*\)` |.*/\1/p' "$KERN_ROOT/kernel/settings.md"
}

# settings_unknown_keys: `file<TAB>key` for every key that kernel/settings.md does not list.
settings_unknown_keys() {
  local f k known pat ok
  known=$(settings_known_keys)
  while IFS= read -r f; do
    [ -f "$f" ] || continue
    while IFS= read -r k; do
      [ -n "$k" ] || continue
      ok=1
      while IFS= read -r pat; do
        case "$pat" in
          *'<'*'>'*) case "$k" in "${pat%%<*}"?*) ok=0 ;; esac ;;
          *) [ "$k" = "$pat" ] && ok=0 ;;
        esac
        [ "$ok" = 0 ] && break
      done <<EOT
$known
EOT
      [ "$ok" = 1 ] && printf '%s\t%s\n' "$f" "$k"
    done <<EOT
$(settings_keys "$f")
EOT
  done <<EOT
$(_settings_files)
EOT
}

# policy_for ACTION: ask|auto|deny for commit, push, pr, tracker or review.post.
policy_for() {
  local key v
  case "$1" in
    review.post) key=review.post_policy ;;
    *) key="$1.policy" ;;
  esac
  v=$(settings_get "$key" ask)
  case "$v" in
    auto|deny) printf '%s\n' "$v" ;;
    *) printf 'ask\n' ;;
  esac
}

# kern_enabled: exit 0 unless the resolved `kern` key is `off`.
kern_enabled() {
  [ "$(settings_get kern on)" != off ]
}

# list_has LIST ITEM: exit 0 when the comma-separated LIST contains ITEM (whitespace trimmed).
list_has() {
  local rest="$1," item
  while [ -n "$rest" ]; do
    item=${rest%%,*}; rest=${rest#*,}
    item=$(printf '%s' "$item" | sed 's/^[ \t]*//; s/[ \t]*$//')
    [ -n "$item" ] && [ "$item" = "$2" ] && return 0
  done
  return 1
}
```

- [ ] **Step 5: Write `scripts/kern-detect`**

```bash
#!/usr/bin/env bash
# Detects a settings value from the repo. Prints `value<TAB>evidence`; exit 3 when not detectable.
# Keys: base_branch, branch.pattern, commit.convention, test.focused, test.full, typecheck, lint,
# build, tracker, pr.template.
set -uo pipefail
KERN_ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
export KERN_ROOT
# shellcheck source=hooks/lib/json.sh
. "$KERN_ROOT/hooks/lib/json.sh"
# shellcheck source=hooks/lib/settings.sh
. "$KERN_ROOT/hooks/lib/settings.sh"
key="${1-}"
CWD="$PWD"
M=$(kern_main_root "$CWD") || { echo "kern-detect: not a git repository" >&2; exit 2; }
KERN_MAIN="$M"
export CWD KERN_MAIN

out() { printf '%s\t%s\n' "$1" "$2"; exit 0; }
none() { echo "kern-detect: $key not detectable: $1" >&2; exit 3; }

# share COUNT TOTAL: exit 0 when COUNT is at least 60% of TOTAL and TOTAL is at least 5.
share() { [ "$2" -ge 5 ] && [ $(($1 * 100)) -ge $(($2 * 60)) ]; }

base() {
  local b
  b=$(git -C "$M" symbolic-ref --short refs/remotes/origin/HEAD 2>/dev/null) || return 1
  printf '%s\n' "${b#origin/}"
}

# pm: the package manager that owns package.json, from its lockfile.
pm() {
  if [ -f "$M/pnpm-lock.yaml" ]; then echo pnpm
  elif [ -f "$M/yarn.lock" ]; then echo yarn
  elif [ -f "$M/bun.lockb" ] || [ -f "$M/bun.lock" ]; then echo bun
  else echo npm
  fi
}

# script NAME: exit 0 and print the run command when package.json has scripts.NAME.
script() {
  local scripts
  [ -f "$M/package.json" ] || return 1
  scripts=$(KERN_INPUT=$(cat "$M/package.json") json_get_raw scripts) || return 1
  KERN_INPUT="$scripts" json_get "$1" >/dev/null || return 1
  if [ "$1" = test ]; then
    printf '%s test\n' "$(pm)"
  else
    printf '%s run %s\n' "$(pm)" "$1"
  fi
}

make_target() {
  [ -f "$M/Makefile" ] && grep -Eq "^$1:" "$M/Makefile"
}

case "$key" in
  base_branch)
    b=$(base) || none "refs/remotes/origin/HEAD is not set (git remote set-head origin --auto)"
    out "$b" "refs/remotes/origin/HEAD"
    ;;
  branch.pattern)
    names=$(git -C "$M" for-each-ref --sort=-committerdate --count=40 --format='%(refname:short)' refs/remotes/origin |
      sed 's#^origin/##' | grep -v -x -e HEAD -e origin -e "$(base 2>/dev/null || echo main)" | head -n 30)
    total=$(printf '%s\n' "$names" | grep -c . || true)
    n=$(printf '%s\n' "$names" | grep -Ec '^[A-Z][A-Z0-9]+-[0-9]+/' || true)
    share "$n" "$total" && out '{id}/{slug}' "$n of $total remote branches match ID/slug"
    n=$(printf '%s\n' "$names" | grep -Ec '^[A-Z][A-Z0-9]+-[0-9]+-' || true)
    share "$n" "$total" && out '{id}-{slug}' "$n of $total remote branches match ID-slug"
    prefix=$(printf '%s\n' "$names" | sed -n 's#^\([a-z]*\)/.*#\1#p' | sort | uniq -c | sort -rn | awk 'NR == 1 { print $1, $2 }')
    if [ -n "$prefix" ] && share "${prefix%% *}" "$total"; then
      out "${prefix#* }/{slug}" "${prefix%% *} of $total remote branches start with ${prefix#* }/"
    fi
    none "no branch shape covers 60% of the last $total remote branches"
    ;;
  commit.convention)
    ref=origin/$(base 2>/dev/null || echo HEAD)
    git -C "$M" rev-parse -q --verify "$ref" >/dev/null || ref=HEAD
    subjects=$(git -C "$M" log --format=%s -30 "$ref" 2>/dev/null)
    total=$(printf '%s\n' "$subjects" | grep -c . || true)
    n=$(printf '%s\n' "$subjects" | grep -Ec '^[A-Z][A-Z0-9]+-[0-9]+: ' || true)
    share "$n" "$total" && out '^[A-Z][A-Z0-9]+-[0-9]+: ' "$n of the last $total subjects start with ID: "
    re='^(feat|fix|chore|docs|refactor|test|perf|build|ci|style|revert)(\([^)]+\))?!?: '
    n=$(printf '%s\n' "$subjects" | grep -Ec "$re" || true)
    share "$n" "$total" && out "$re" "$n of the last $total subjects are Conventional Commits"
    none "no subject shape covers 60% of the last $total commits"
    ;;
  test.full)
    c=$(script test) && out "$c" "package.json scripts.test"
    make_target test && out "make test" "Makefile target test"
    [ -f "$M/pyproject.toml" ] && grep -q 'pytest' "$M/pyproject.toml" && out "pytest" "pyproject.toml mentions pytest"
    [ -f "$M/go.mod" ] && out "go test ./..." "go.mod"
    [ -f "$M/Cargo.toml" ] && out "cargo test" "Cargo.toml"
    none "no package.json scripts.test, Makefile test target, pytest, go.mod or Cargo.toml"
    ;;
  test.focused)
    c=$(script test) && out "$c -- {file}" "package.json scripts.test with a path argument"
    [ -f "$M/pyproject.toml" ] && grep -q 'pytest' "$M/pyproject.toml" && out "pytest {file}" "pyproject.toml mentions pytest"
    [ -f "$M/go.mod" ] && out "go test ./{dir}" "go.mod"
    [ -f "$M/Cargo.toml" ] && out "cargo test {name}" "Cargo.toml"
    none "no focused test runner found"
    ;;
  typecheck)
    for s in typecheck type-check tsc check-types; do
      c=$(script "$s") && out "$c" "package.json scripts.$s"
    done
    make_target typecheck && out "make typecheck" "Makefile target typecheck"
    [ -f "$M/tsconfig.json" ] && out "npx tsc --noEmit" "tsconfig.json at the repo root"
    [ -f "$M/pyproject.toml" ] && grep -q 'mypy' "$M/pyproject.toml" && out "mypy ." "pyproject.toml mentions mypy"
    [ -f "$M/go.mod" ] && out "go vet ./..." "go.mod"
    [ -f "$M/Cargo.toml" ] && out "cargo check" "Cargo.toml"
    none "no typecheck script, tsconfig.json, mypy, go.mod or Cargo.toml"
    ;;
  lint)
    c=$(script lint) && out "$c" "package.json scripts.lint"
    make_target lint && out "make lint" "Makefile target lint"
    [ -f "$M/pyproject.toml" ] && grep -q 'ruff' "$M/pyproject.toml" && out "ruff check ." "pyproject.toml mentions ruff"
    [ -f "$M/Cargo.toml" ] && out "cargo clippy" "Cargo.toml"
    none "no lint script, Makefile target, ruff or Cargo.toml"
    ;;
  build)
    c=$(script build) && out "$c" "package.json scripts.build"
    make_target build && out "make build" "Makefile target build"
    [ -f "$M/go.mod" ] && out "go build ./..." "go.mod"
    [ -f "$M/Cargo.toml" ] && out "cargo build" "Cargo.toml"
    none "no build script, Makefile target, go.mod or Cargo.toml"
    ;;
  tracker)
    url=$(git -C "$M" remote get-url origin 2>/dev/null) || none "no origin remote"
    case "$url" in
      *github.com*) out github "origin is on github.com; a tracker MCP server, if connected, is checked by /kern:help setup" ;;
      *gitlab*) out gitlab "origin is on gitlab" ;;
    esac
    none "origin host is not github or gitlab"
    ;;
  pr.template)
    for p in .github/pull_request_template.md .github/PULL_REQUEST_TEMPLATE.md docs/pull_request_template.md pull_request_template.md; do
      [ -f "$M/$p" ] && out "$p" "file exists"
    done
    none "no pull request template"
    ;;
  *)
    echo "usage: kern-detect base_branch|branch.pattern|commit.convention|test.focused|test.full|typecheck|lint|build|tracker|pr.template" >&2
    exit 2
    ;;
esac
```

```bash
# shellcheck shell=bash
# kern session state: one flat `key: value` file per session, written only by kern hooks.
# Needs settings.sh. Guard G16 denies tool writes under state_dir.

state_dir() {
  printf '%s/sessions\n' "${CLAUDE_PLUGIN_DATA:-$HOME/.claude/plugins/data/kern-kern}"
}

# state_file SID: path of the session's state file. Exit 2 for an id outside [A-Za-z0-9_-].
state_file() {
  case "$1" in
    '' | *[!A-Za-z0-9_-]*) return 2 ;;
  esac
  printf '%s/%s.state\n' "$(state_dir)" "$1"
}

# state_get SID KEY: prints the value. Exit 1 unset, 2 bad id or unsafe file.
state_get() {
  local f
  f=$(state_file "$1") || return 2
  [ -L "$f" ] && return 2
  [ -f "$f" ] || return 1
  LC_ALL=C awk -v k="$2" 'index($0, k ": ") == 1 { v = substr($0, length(k) + 3); found = 1 }
    END { if (found) { print v; exit 0 } exit 1 }' "$f"
}

# state_set SID KEY=VALUE...: atomic update (temp file in the same dir, then mv), mode 0600.
state_set() {
  local sid="$1" f dir tmp kv k v content
  shift
  f=$(state_file "$sid") || return 2
  dir=$(dirname "$f")
  (umask 077 && mkdir -p "$dir") || return 2
  [ -L "$dir" ] && return 2
  [ -L "$f" ] && return 2
  content=""
  [ -f "$f" ] && content=$(cat "$f")
  for kv in "$@"; do
    k=${kv%%=*}
    v=${kv#*=}
    case "$k" in '' | *[!a-z_]*) return 2 ;; esac
    case "$v" in *"
"*) return 2 ;; esac
    content=$(printf '%s\n' "$content" | LC_ALL=C awk -v k="$k" 'index($0, k ": ") != 1 && $0 != ""')
    content="$content
$k: $v"
  done
  tmp=$(umask 077 && mktemp "$dir/.state.XXXXXX") || return 2
  printf '%s\n' "$content" | sed '/^$/d' >"$tmp" || { rm -f "$tmp"; return 2; }
  mv -f "$tmp" "$f"
}

# now_iso: current UTC time, ISO 8601.
now_iso() {
  date -u +%Y-%m-%dT%H:%M:%SZ
}

# state_reset SID: defaults from settings, autopilot off.
state_reset() {
  local voice surface
  voice=$(settings_get mode.voice normal)
  surface=$(settings_get mode.surface auto)
  case "$voice" in normal | terse) ;; *) voice=normal ;; esac
  case "$surface" in chat | auto | html) ;; *) surface=auto ;; esac
  state_set "$1" "voice=$voice" "surface=$surface" "autopilot=off" "since=$(now_iso)"
}

# autopilot_on SID: exit 0 only when no settings layer says `autopilot: denied` and the state says on.
autopilot_on() {
  [ "$(settings_get autopilot allowed)" = denied ] && return 1
  [ "$(state_get "$1" autopilot 2>/dev/null)" = on ]
}
```

```bash
# Template rendering for the kernel and the subagent kernel. Literal replacement (no regex), so
# values may hold any character. Values come from K_VERSION, K_ROOT, K_KERN, K_MODE, K_AUTOPILOT,
# K_VOICE and K_SETTINGS; a line that is exactly {SETTINGS} or {VOICE} is replaced by that value.

# render_template FILE
render_template() {
  K_VERSION="${K_VERSION-}" K_ROOT="${K_ROOT-}" K_KERN="${K_KERN-}" K_MODE="${K_MODE-}" \
    K_AUTOPILOT="${K_AUTOPILOT-}" K_VOICE="${K_VOICE-}" K_SETTINGS="${K_SETTINGS-}" \
    LC_ALL=C awk '
    function rep(s, ph, val,   out, p) {
      out = ""
      while ((p = index(s, ph)) > 0) { out = out substr(s, 1, p - 1) val; s = substr(s, p + length(ph)) }
      return out s
    }
    $0 == "{SETTINGS}" { if (ENVIRON["K_SETTINGS"] != "") print ENVIRON["K_SETTINGS"]; next }
    $0 == "{VOICE}" { if (ENVIRON["K_VOICE"] != "") print ENVIRON["K_VOICE"]; next }
    {
      s = $0
      s = rep(s, "{VERSION}", ENVIRON["K_VERSION"])
      s = rep(s, "{KERN}", ENVIRON["K_KERN"])
      s = rep(s, "{ROOT}", ENVIRON["K_ROOT"])
      s = rep(s, "{MODE}", ENVIRON["K_MODE"])
      s = rep(s, "{AUTOPILOT}", ENVIRON["K_AUTOPILOT"])
      print s
    }' "$1"
}

# kern_version: the version in .claude-plugin/plugin.json.
kern_version() {
```

```bash
#!/usr/bin/env bash
# kern UserPromptSubmit and UserPromptExpansion: applies mode and autopilot switches the user typed,
# then prints the mode line and a short reminder when the session is outside the default preset.
# Plain stdout is added to Claude's context.
KERN_ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
export KERN_ROOT
for lib in json settings state render; do
  # shellcheck source=/dev/null
  . "$KERN_ROOT/hooks/lib/$lib.sh"
done

# Wrappers Claude Code puts around prompts it starts itself. A wrapped prompt never switches anything.
KERN_WRAPPER_TAGS="<task-notification <cross-session-message <scheduled-task <teammate-message <channel-message"

# shellcheck disable=SC2034 # read by the json.sh functions
KERN_INPUT=$(cat)
EVENT=$(json_get hook_event_name) || EVENT=UserPromptSubmit
SID=$(json_get session_id) || exit 0
CWD=$(json_get cwd) || CWD="$PWD"
KERN_MAIN=$(kern_main_root "$CWD" 2>/dev/null) || KERN_MAIN=""
export CWD KERN_MAIN
kern_enabled || exit 0
state_file "$SID" >/dev/null || exit 0
state_get "$SID" voice >/dev/null 2>&1 || state_reset "$SID"

NOTICE=""
SHOW_LINE=0
CHANGED_VOICE=""
CHANGED_SURFACE=""
AP_TURNED_ON=0

lower() { tr '[:upper:]' '[:lower:]'; }

# apply_mode ARGS: words combine; an unknown word changes nothing.
apply_mode() {
  local args w voice="" surface="" reset=0
  args=$(printf '%s' "$1" | lower)
  SHOW_LINE=1
  for w in $args; do
    case "$w" in
      terse | normal) voice="$w" ;;
      chat | auto | html) surface="$w" ;;
      default) reset=1 ;;
      status) ;;
      *)
        NOTICE="kern: mode argument not recognized, mode unchanged."
        return 0
        ;;
    esac
  done
  if [ "$reset" = 1 ]; then
    [ -n "$voice" ] || voice=$(settings_get mode.voice normal)
    [ -n "$surface" ] || surface=$(settings_get mode.surface auto)
  fi
  set_voice "$voice"
  set_surface "$surface"
}

set_voice() {
  [ -n "$1" ] || return 0
  [ "$(state_get "$SID" voice 2>/dev/null)" = "$1" ] && return 0
  state_set "$SID" "voice=$1" && CHANGED_VOICE="$1"
}

set_surface() {
  [ -n "$1" ] || return 0
  [ "$(state_get "$SID" surface 2>/dev/null)" = "$1" ] && return 0
  state_set "$SID" "surface=$1" && CHANGED_SURFACE="$1"
}

# apply_autopilot ARGS ALLOW_ON: ALLOW_ON is 1 only for a command the user typed.
apply_autopilot() {
  local arg
  arg=$(printf '%s' "$1" | lower | awk '{ print $1 }')
  SHOW_LINE=1
  case "$arg" in
    on)
      [ "$2" = 1 ] || return 0
      if [ "$(settings_get autopilot allowed)" = denied ]; then
        NOTICE="kern: autopilot denied by $(settings_source autopilot)."
        return 0
      fi
      if [ "$(state_get "$SID" autopilot 2>/dev/null)" != on ]; then
        state_set "$SID" autopilot=on "since=$(now_iso)" && AP_TURNED_ON=1
      fi
      ;;
    off) state_set "$SID" autopilot=off ;;
    "" | status) ;;
    *) NOTICE="kern: autopilot argument not recognized; use on, off or status." ;;
  esac
}

# dispatch NAME ARGS ALLOW_ON: NAME is a command name with or without the leading slash.
dispatch() {
  case "${1#/}" in
    kern:mode | mode) apply_mode "$2" ;;
    kern:autopilot | autopilot) apply_autopilot "$2" "$3" ;;
  esac
}

wrapped() {
  local t
  for t in $KERN_WRAPPER_TAGS; do
    case "$1" in *"$t"*) return 0 ;; esac
  done
  return 1
}

# natural PROMPT: prompt-initial switches only, with negation and question guards.
natural() {
  local first
  first=$(printf '%s\n' "$1" | sed -n '/[^[:space:]]/{p;q;}' | lower | sed -E 's/^[[:space:]]+//; s/^(please|ok|okay),? //')
  case "$first" in
    "don't"* | "do not"* | "dont"* | never* | no\ * | "not "*) return 0 ;;
    *'?'* | what* | how* | why* | does* | do\ * | is\ * | are\ * | can\ * | could\ * | should\ * | when\ * | which\ * | who\ *) return 0 ;;
  esac
  case "$first" in
    "terse mode"* | "go terse"* | "be terse"* | "switch to terse"* | "terse on"*) _nl_ok "$first" && set_voice terse && SHOW_LINE=1 ;;
    "normal mode"* | "back to normal"* | "stop terse"* | "terse off"* | "normal voice"*) _nl_ok "$first" && set_voice normal && SHOW_LINE=1 ;;
    "html mode"* | "go html"* | "switch to html"* | "html on"*) _nl_ok "$first" && set_surface html && SHOW_LINE=1 ;;
    "stop html"* | "html off"*) _nl_ok "$first" && set_surface "$(settings_get mode.surface auto | sed 's/^html$/auto/')" && SHOW_LINE=1 ;;
    "chat only"* | "chat mode"*) _nl_ok "$first" && set_surface chat && SHOW_LINE=1 ;;
    "stop autopilot"* | "autopilot off"*) _nl_ok "$first" && state_set "$SID" autopilot=off && SHOW_LINE=1 ;;
  esac
  return 0
}

# _nl_ok FIRST: the trigger is the whole first line or is followed by punctuation or "and".
_nl_ok() {
  printf '%s\n' "$1" | grep -Eq '^(terse mode|go terse|be terse|switch to terse|terse on|normal mode|back to normal|stop terse|terse off|normal voice|html mode|go html|switch to html|html on|stop html|html off|chat only|chat mode|stop autopilot|autopilot off)([[:space:]]*[.!,;:]|[[:space:]]+(and|then|now|please)([[:space:]]|$)|[[:space:]]*$)'
}

if [ "$EVENT" = UserPromptExpansion ]; then
  NAME=$(json_get command_name) || NAME=""
  ARGS=$(json_get command_args) || ARGS=""
  SRC=$(json_get command_source) || SRC=""
  PROMPT=$(json_get prompt) || PROMPT=""
  case "${NAME#/}" in
    kern:mode | kern:autopilot) dispatch "$NAME" "$ARGS" 1 ;;
    mode | autopilot)
      case "$PROMPT" in
        "/kern:${NAME#/}"* | "/${NAME#/}"*) [ "$SRC" = plugin ] && dispatch "$NAME" "$ARGS" 1 ;;
      esac
      ;;
  esac
else
  PROMPT=$(json_get prompt) || PROMPT=""
  wrapped "$PROMPT" && exit 0
  TRIM=$(printf '%s' "$PROMPT" | sed -n '/[^[:space:]]/,$p' | sed '1s/^[[:space:]]*//')
  case "$TRIM" in
    "<command-message>"* | "<command-name>"*)
      NAME=$(printf '%s' "$TRIM" | sed -n 's/.*<command-name>[[:space:]]*\([^<[:space:]]*\)[[:space:]]*<\/command-name>.*/\1/p' | head -n 1)
      ARGS=$(printf '%s' "$TRIM" | tr '\n' ' ' | sed -n 's/.*<command-args>[[:space:]]*\([^<]*\)<\/command-args>.*/\1/p' | head -n 1)
      dispatch "$NAME" "$ARGS" 1
      ;;
    /kern:mode* | /kern:autopilot*)
      NAME=$(printf '%s' "$TRIM" | awk 'NR == 1 { print $1 }')
      ARGS=$(printf '%s' "$TRIM" | awk 'NR == 1 { $1 = ""; sub(/^ /, ""); print }')
      dispatch "$NAME" "$ARGS" 1
      ;;
    /*) ;;
    *) natural "$TRIM" ;;
  esac
fi

[ "$EVENT" = UserPromptExpansion ] && [ "$SHOW_LINE" = 0 ] && exit 0
[ -n "$NOTICE" ] && printf '%s\n' "$NOTICE"
case "$CHANGED_VOICE" in
  terse) cat "$KERN_ROOT/modes/terse.md" ;;
```

```bash
# shellcheck shell=bash
# PreToolUse votes. Each guard calls `vote`; the dispatcher calls `emit_decision` once.
# Needs json.sh. Reads AUTOPILOT (1 under autopilot).

_KERN_VOTE=""
_KERN_R_DENY=""
_KERN_R_ASK=""
_KERN_R_ALLOW=""

# vote allow|ask|deny GUARD REASON: keeps the strictest decision (deny > ask > allow).
vote() {
  local d="$1" line="$2: $3"
  case "$d" in
    deny)
      _KERN_VOTE=deny
      _KERN_R_DENY="${_KERN_R_DENY:+$_KERN_R_DENY; }$line"
      ;;
    allow)
      [ -z "$_KERN_VOTE" ] && _KERN_VOTE=allow
      _KERN_R_ALLOW="${_KERN_R_ALLOW:+$_KERN_R_ALLOW; }$line"
      ;;
    *)
      [ "$_KERN_VOTE" != deny ] && _KERN_VOTE=ask
      _KERN_R_ASK="${_KERN_R_ASK:+$_KERN_R_ASK; }$line"
      ;;
  esac
}

# fail_closed REASON: input could not be parsed; never allow.
fail_closed() {
  vote ask G0 "$1"
}

# emit_decision: prints the PreToolUse JSON for the strictest vote, or nothing when nobody voted.
emit_decision() {
  local d="$_KERN_VOTE" r
  [ -n "$d" ] || return 0
  case "$d" in
    deny) r="$_KERN_R_DENY" ;;
    ask) r="$_KERN_R_ASK" ;;
    *) r="$_KERN_R_ALLOW" ;;
  esac
  if [ "$d" = ask ] && [ "${AUTOPILOT:-0}" = 1 ]; then
    d=deny
    r="$r (autopilot: nobody to ask)"
  fi
  printf '{"hookSpecificOutput":{"hookEventName":"PreToolUse","permissionDecision":"%s","permissionDecisionReason":"%s"}}\n' \
    "$d" "$(printf 'kern %s' "$r" | json_escape)"
}
```

```bash
# shellcheck shell=bash
# Shell and git parsing for guards. Needs settings.sh. Reads CWD and KERN_MAIN.

# git_words CMD: one simple command per line. Splits on ; & && || | and newlines outside quotes,
# backticks and $( ). The body of `bash -c '...'`, `sh -c` and `eval '...'` is split again and
# printed after its wrapper, so a chained command inside a string is still seen.
git_words() {
  local seg inner body
  _split_words "$1" | while IFS= read -r seg; do
    printf '%s\n' "$seg"
    _subst_bodies "$seg" | while IFS= read -r body; do
      [ -n "$body" ] && git_words "$body"
    done
    inner=$(printf '%s\n' "$seg" | sed -n -E "s/^(env +([A-Za-z_][A-Za-z0-9_]*=[^ ]* +)*)?((ba|z|da)?sh +(-[a-z]+ +)*-c|eval) +//p")
    [ -n "$inner" ] || continue
    inner=$(_shell_words "$inner" | head -n 1)
    [ -n "$inner" ] && git_words "$inner"
  done
}

# _subst_bodies STR: the body of each outermost $( ) and backtick pair, one per line.
_subst_bodies() {
  printf '%s' "$1" | LC_ALL=C awk -v sq="'" '
    { buf = buf (NR > 1 ? " " : "") $0 }
    END {
      n = length(buf); q = ""; depth = 0
      for (i = 1; i <= n; i++) {
        c = substr(buf, i, 1)
        if (q == sq) { if (c == sq) q = ""; continue }
        if (c == "\\") { i++; continue }
        if (depth == 0 && c == "`") {
          e = index(substr(buf, i + 1), "`")
          if (e) { print substr(buf, i + 1, e - 1); i += e }
          continue
        }
        if (c == "$" && substr(buf, i + 1, 1) == "(") {
          if (depth == 0) s = i + 2
          depth++; i++; continue
        }
        if (depth > 0) {
          if (c == "(") depth++
          else if (c == ")") { depth--; if (depth == 0) print substr(buf, s, i - s) }
          continue
        }
        if (c == sq) q = sq
      }
    }'
}

_split_words() {
  printf '%s' "$1" | LC_ALL=C awk -v sq="'" '
    function emit(s) { gsub(/^[ \t\n]+|[ \t\n]+$/, "", s); if (s != "") print s }
    { buf = buf (NR > 1 ? "\n" : "") $0 }
    END {
      n = length(buf); q = ""; depth = 0; start = 1; i = 1
      while (i <= n) {
        c = substr(buf, i, 1)
        if (q == sq) { if (c == sq) q = ""; i++; continue }
        if (c == "\\") { i += 2; continue }
        if (q == "\"") {
          if (c == "\"") q = ""
          else if (c == "$" && substr(buf, i + 1, 1) == "(") { depth++; i++ }
          else if (c == ")" && depth > 0) depth--
          i++; continue
        }
        if (q == "`") { if (c == "`") q = ""; i++; continue }
        if (c == sq || c == "\"" || c == "`") { q = c; i++; continue }
        if (c == "$" && substr(buf, i + 1, 1) == "(") { depth++; i += 2; continue }
        if (depth > 0) { if (c == "(") depth++; else if (c == ")") depth--; i++; continue }
        if (c == ";" || c == "\n" || c == "&" || c == "|") {
          emit(substr(buf, start, i - start))
          if ((c == "&" || c == "|") && substr(buf, i + 1, 1) == c) i++
          start = i + 1
        }
        i++
      }
      emit(substr(buf, start))
    }'
}

# _shell_words STR: the words of one simple command, quotes removed, one per line.
_shell_words() {
  printf '%s' "$1" | LC_ALL=C awk -v sq="'" '
    { buf = buf (NR > 1 ? " " : "") $0 }
    END {
      n = length(buf); q = ""; w = ""; have = 0
      for (i = 1; i <= n; i++) {
        c = substr(buf, i, 1)
        if (q == sq) { if (c == sq) q = ""; else w = w c; continue }
        if (q == "\"") {
          if (c == "\"") q = ""
          else if (c == "\\" && index("\"\\$`", substr(buf, i + 1, 1))) { i++; w = w substr(buf, i, 1) }
          else w = w c
          continue
        }
        if (c == "\\") { i++; w = w substr(buf, i, 1); have = 1; continue }
        if (c == sq || c == "\"") { q = c; have = 1; continue }
        if (c == " " || c == "\t") { if (have) print w; w = ""; have = 0; continue }
        w = w c; have = 1
      }
      if (have) print w
    }'
}

# git_sub CMDLINE: for a simple git command prints `<dir>\t<subcommand>\t<rest>`. Exit 1 when the
# command is not git. Leading VAR=value words and command/exec/time/nohup/sudo are skipped.
git_sub() {
  local w=() t i=0 n dir="${CWD:-$PWD}" rest=""
  while IFS= read -r t; do w+=("$t"); done <<EOT
$(_shell_words "$1")
EOT
  n=${#w[@]}
  while [ "$i" -lt "$n" ]; do
    case "${w[$i]}" in
      [A-Za-z_]*=*) i=$((i + 1)) ;;
      command | exec | time | nohup | sudo) i=$((i + 1)) ;;
      *) break ;;
    esac
  done
  [ "$i" -lt "$n" ] || return 1
  case "${w[$i]}" in git | */git) ;; *) return 1 ;; esac
  i=$((i + 1))
  while [ "$i" -lt "$n" ]; do
    case "${w[$i]}" in
      -C)
        t="${w[$((i + 1))]-}"
        case "$t" in /*) dir="$t" ;; *) dir="$dir/$t" ;; esac
        i=$((i + 2))
        ;;
      -c) i=$((i + 2)) ;;
      --git-dir=* | --work-tree=* | --namespace=* | --no-pager | --paginate | -p | --bare | --no-replace-objects | --literal-pathspecs | --no-optional-locks) i=$((i + 1)) ;;
      *) break ;;
    esac
  done
  [ "$i" -lt "$n" ] || return 1
  t="${w[$i]}"
  i=$((i + 1))
  while [ "$i" -lt "$n" ]; do
    rest="${rest:+$rest }${w[$i]}"
    i=$((i + 1))
  done
  printf '%s\t%s\t%s\n' "$dir" "$t" "$rest"
}

# cmd_head CMDLINE: the first two words of a simple command after env assignments and wrappers.
cmd_head() {
  _shell_words "$1" | awk '
    !started && /^[A-Za-z_][A-Za-z0-9_]*=/ { next }
    !started && /^(command|exec|time|nohup|sudo)$/ { next }
    { started = 1; out = out (n++ ? " " : "") $0; if (n == 2) exit }
    END { print out }'
}

# in_main_checkout DIR: exit 0 when DIR is inside the main worktree (not a linked worktree).
in_main_checkout() {
  local top main
  top=$(git -C "$1" rev-parse --show-toplevel 2>/dev/null) || return 1
  main=$(kern_main_root "$1") || return 1
  [ "$(cd "$top" && pwd -P)" = "$(cd "$main" && pwd -P)" ]
}

# current_branch DIR
current_branch() {
  git -C "$1" rev-parse --abbrev-ref HEAD 2>/dev/null
}

# base_branch_name: settings base_branch, else origin/HEAD. Exit 1 when neither resolves.
base_branch_name() {
  local b
  if b=$(settings_get base_branch) && [ -n "$b" ]; then
    printf '%s\n' "$b"
    return 0
  fi
  b=$(git -C "${KERN_MAIN:-${CWD:-$PWD}}" symbolic-ref --short refs/remotes/origin/HEAD 2>/dev/null) || return 1
  printf '%s\n' "${b#origin/}"
}

# branch_protected BRANCH: base branch, branch.protected or deploy.envs. With no resolvable base,
# main, master, trunk and develop count as protected.
branch_protected() {
  local base
  if base=$(base_branch_name); then
    [ "$1" = "$base" ] && return 0
  else
    case "$1" in main | master | trunk | develop) return 0 ;; esac
  fi
  list_has "$(settings_get branch.protected '')" "$1" && return 0
  list_has "$(settings_get deploy.envs '')" "$1" && return 0
  return 1
}

# push_targets DIR REST: remote branch names a `git push` writes, one per line. `:x` and
# --delete targets print as `x`. No refspec means the current branch.
push_targets() {
  local dir="$1" w=() t i=0 n pos=0 any=0
  while IFS= read -r t; do [ -n "$t" ] && w+=("$t"); done <<EOT
$(_shell_words "$2")
EOT
  n=${#w[@]}
  while [ "$i" -lt "$n" ]; do
    t="${w[$i]}"
    i=$((i + 1))
    case "$t" in
      --repo | --push-option | -o | --receive-pack | --exec) i=$((i + 1)); continue ;;
      -*) continue ;;
    esac
    pos=$((pos + 1))
    [ "$pos" -eq 1 ] && continue
    any=1
    t=${t#+}
    case "$t" in
      *:*) t=${t#*:} ;;
    esac
    [ "$t" = HEAD ] && t=$(current_branch "$dir")
    printf '%s\n' "${t#refs/heads/}"
  done
  [ "$any" = 1 ] || current_branch "$dir"
}

# with_timeout SECS CMD...: runs CMD, killing it after SECS seconds. Returns CMD's exit code.
with_timeout() {
  local secs="$1" pid w rc
  shift
  "$@" &
  pid=$!
  (sleep "$secs" && kill "$pid") >/dev/null 2>&1 &
  w=$!
  wait "$pid"
  rc=$?
  pkill -P "$w" >/dev/null 2>&1
  kill "$w" >/dev/null 2>&1
  wait "$w" 2>/dev/null
  return "$rc"
}

# gh_sub CMDLINE: for `gh <group> <verb> ...` prints `<group> <verb>`; exit 1 for anything else.
gh_sub() {
  local out
  out=$(_shell_words "$1" | awk '
    !s && /^[A-Za-z_][A-Za-z0-9_]*=/ { next }
    !s && /^(command|exec|time|nohup|sudo)$/ { next }
    { s = 1; w[++n] = $0; if (n == 3) exit }
    END { if (w[1] == "gh" && n >= 3) print w[2] " " w[3]; else if (w[1] == "gh" && n == 2) print w[2] }')
  [ -n "$out" ] || return 1
  printf '%s\n' "$out"
}

# word_value WORDS FLAG...: the value after the first of FLAG in the newline-separated WORDS
# (`--flag value` or `--flag=value`). Exit 1 when absent.
word_value() {
  local words="$1" w prev="" f
  shift
  while IFS= read -r w; do
    for f in "$@"; do
      if [ "$prev" = "$f" ]; then printf '%s\n' "$w"; return 0; fi
      case "$w" in "$f="*) printf '%s\n' "${w#"$f"=}"; return 0 ;; esac
    done
    prev="$w"
  done <<EOT
$words
EOT
  return 1
}

# word_has WORDS FLAG...: exit 0 when any FLAG is one of the newline-separated WORDS.
word_has() {
  local words="$1" w f
  shift
  while IFS= read -r w; do
    for f in "$@"; do [ "$w" = "$f" ] && return 0; done
  done <<EOT
$words
EOT
  return 1
}
```

```bash
# shellcheck shell=bash
# G1 git safety: main-checkout state changes, push, force push, merge. Design spec 8.3.

guard_g01() {
  [ "$TOOL" = Bash ] || return 0
  local cmd seg parsed dir sub rest
  cmd=$(ti_get command) || { fail_closed "Bash call without a command"; return 0; }
  while IFS= read -r seg; do
    case "$(cmd_head "$seg")" in
      "gh pr") case " $seg " in *" merge "*) _g01_merge "gh pr merge" ;; esac ;;
      "gh api") case "$seg" in *"/merge"*) _g01_merge "gh api merge endpoint" ;; esac ;;
    esac
    parsed=$(git_sub "$seg") || continue
    dir=${parsed%%	*}
    rest=${parsed#*	}
    sub=${rest%%	*}
    rest=${rest#*	}
    _g01_git "$dir" "$sub" "$rest"
  done <<EOT
$(git_words "$cmd")
EOT
}

_g01_merge() {
  vote ask G1 "$1 merges a PR; merge always needs the user's word"
  [ "$AUTOPILOT" = 1 ] && vote deny G1 "$1 under autopilot: merge stays human"
}

# _g01_main_op DIR WHAT: ask in the main checkout (deny under autopilot); nothing elsewhere.
_g01_main_op() {
  in_main_checkout "$1" || return 0
  if [ "$AUTOPILOT" = 1 ]; then
    vote deny G1 "git $2 in the main checkout (D3); use a kern worktree"
  else
    vote ask G1 "git $2 in the main checkout changes shared state (D3)"
  fi
}

_g01_git() {
  local dir="$1" sub="$2" rest="$3"
  case "$sub" in
    switch | rebase | bisect) _g01_main_op "$dir" "$sub" ;;
    checkout)
      case " $rest " in
        *" -b "* | *" -B "* | *" --orphan "*) _g01_main_op "$dir" "checkout -b" ;;
        *) _g01_main_op "$dir" checkout ;;
      esac
      ;;
    reset) case " $rest " in *" --hard "* | *" --merge "* | *" --keep "*) _g01_main_op "$dir" "reset $rest" ;; esac ;;
    stash) case "$rest" in list* | show*) ;; *) _g01_main_op "$dir" stash ;; esac ;;
    clean) case " $rest " in *" -n "* | *" --dry-run "*) ;; *) _g01_main_op "$dir" clean ;; esac ;;
    merge)
      case " $rest " in *" --abort "*) return 0 ;; esac
      vote ask G1 "git merge"
      [ "$AUTOPILOT" = 1 ] && vote deny G1 "git merge under autopilot"
      ;;
    branch)
      case " $rest " in
        *" -D "* | *" --delete --force "* | *" -d --force "*) _g01_destructive "git branch -D" ;;
      esac
      ;;
    worktree)
      case " $rest " in
        " remove "*) case " $rest " in *" --force "* | *" -f "*) _g01_destructive "git worktree remove --force" ;; esac ;;
      esac
      ;;
    push) _g01_push "$dir" "$rest" ;;
  esac
}

_g01_destructive() {
  vote ask G1 "$1 discards work"
  [ "$AUTOPILOT" = 1 ] && vote deny G1 "$1 under autopilot"
}

# _g01_own_branch DIR BRANCH: every commit on BRANCH not on the base was authored by user.email.
_g01_own_branch() {
  local me base authors
  me=$(git -C "$1" config user.email 2>/dev/null) || return 1
  base=$(base_branch_name) || return 1
  authors=$(git -C "$1" log --format=%ae "origin/$base..$2" 2>/dev/null | sort -u) || return 1
  [ -z "$authors" ] || [ "$authors" = "$me" ]
}

_g01_push() {
  local dir="$1" rest="$2" force=none t cur targets policy
  case " $rest " in
    *" --force-with-lease"* | *" --force-if-includes"*) force=lease ;;
  esac
  case " $rest " in
    *" --force "* | *" -f "* | *" --mirror "*) force=hard ;;
  esac
  while IFS= read -r t; do
    case "$t" in
      +*) force=hard ;;
      --*) ;;
      -*f*) force=hard ;;
    esac
  done <<EOT
$(_shell_words "$rest")
EOT
  targets=$(push_targets "$dir" "$rest")
  if [ "$force" = hard ]; then
    vote deny G1 "plain force push; use --force-with-lease on your own branch"
    return 0
  fi
  cur=$(current_branch "$dir")
  while IFS= read -r t; do
    [ -n "$t" ] || continue
    case " $rest " in *" --delete "* | *" -d "*) _g01_destructive "git push --delete $t"; continue ;; esac
    if branch_protected "$t"; then
      vote ask G1 "push to protected branch $t"
      [ "$AUTOPILOT" = 1 ] && vote deny G1 "push to protected branch $t under autopilot"
      continue
    fi
    if [ "$force" = lease ]; then
      if [ "$AUTOPILOT" = 1 ]; then
        if [ "$(settings_get rebase.push ask)" = autopilot ] && _g01_own_branch "$dir" "$t"; then
          vote allow G1 "lease push of own branch $t (rebase.push: autopilot)"
        else
          vote deny G1 "lease push of $t needs rebase.push: autopilot and only your own commits"
        fi
      else
        if _g01_own_branch "$dir" "$t"; then
          vote ask G1 "force-with-lease push of $t"
        else
          vote deny G1 "$t has commits by other authors; it is shared and never force-pushed"
        fi
      fi
      continue
    fi
    if [ "$AUTOPILOT" = 1 ]; then
      if [ "$t" = "$cur" ]; then
        vote allow G1 "autopilot push of the current branch $t"
      else
        vote deny G1 "autopilot pushes only the current branch ($cur), not $t"
      fi
      continue
    fi
    policy=$(policy_for push)
    case "$policy" in
      auto) vote allow G1 "push.policy auto: push $t" ;;
      deny) vote deny G1 "push.policy deny" ;;
      *) vote ask G1 "push $t" ;;
    esac
  done <<EOT
$targets
EOT
}
```

```bash
# G2 PR create: drafts only, no duplicate PR for a head, `gh pr ready` stays human under autopilot.

guard_g02() {
  [ "$TOOL" = Bash ] || return 0
  local cmd seg
  cmd=$(ti_get command) || return 0
  while IFS= read -r seg; do
    case "$(gh_sub "$seg")" in
      "pr create") _g02_create "$seg" ;;
      "pr ready")
        word_has "$(_shell_words "$seg")" --undo && continue
        vote ask G2 "gh pr ready marks a PR ready for review"
        [ "$AUTOPILOT" = 1 ] && vote deny G2 "gh pr ready under autopilot: drafts only"
        ;;
    esac
  done <<EOT
$(git_words "$cmd")
EOT
}

# _g02_states HEAD: states of PRs whose head is HEAD, one per line. Exit 2 when gh cannot answer.
_g02_states() {
  command -v gh >/dev/null 2>&1 || return 2
  (cd "$CWD" 2>/dev/null && with_timeout 10 gh pr list --head "$1" --state all --json state --jq '.[].state') 2>/dev/null || return 2
}

_g02_create() {
  local words head states policy
  words=$(_shell_words "$1")
  if ! word_has "$words" --draft -d; then
    vote deny G2 "open PRs as drafts: add --draft"
    return 0
  fi
  head=$(word_value "$words" --head -H) || head=$(current_branch "$CWD")
  if ! states=$(_g02_states "$head"); then
    vote ask G2 "could not check for an existing PR on $head (gh unavailable)"
    return 0
  fi
  case "$states" in
    *OPEN*) vote deny G2 "a PR is already open for $head; report it instead of opening another"; return 0 ;;
    *MERGED* | *CLOSED*) vote ask G2 "a merged or closed PR already exists for $head"; return 0 ;;
  esac
  if [ "$AUTOPILOT" = 1 ]; then
    vote allow G2 "autopilot: draft PR for $head after dedup"
    return 0
  fi
  policy=$(policy_for pr)
  case "$policy" in
    auto) vote allow G2 "pr.policy auto: draft PR for $head" ;;
    deny) vote deny G2 "pr.policy deny" ;;
    *) vote ask G2 "open a draft PR for $head" ;;
  esac
}
```

```bash
# shellcheck shell=bash
# G3 review posting: no self-approval, findings carry a taxonomy label, posting asks.

guard_g03() {
  case "$TOOL" in
    Skill) _g03_skill; return 0 ;;
    Bash) ;;
    *) return 0 ;;
  esac
  local cmd seg
  cmd=$(ti_get command) || return 0
  while IFS= read -r seg; do
    case "$(gh_sub "$seg")" in
      "pr review") _g03_review "$seg" ;;
      "pr comment") _g03_post "gh pr comment" ;;
      api*)
        case "$seg" in
          *"/reviews"* | *"/comments"*) _g03_api "$seg" ;;
        esac
        ;;
    esac
  done <<EOT
$(git_words "$cmd")
EOT
}

# The built-in code-review skill: --comment posts at once; --fix edits the tree it runs in.
_g03_skill() {
  case "$TOOL_INPUT" in *code-review*) ;; *) return 0 ;; esac
  case "$TOOL_INPUT" in
    *--comment*) vote ask G3 "code-review --comment posts findings to the PR immediately" ;;
  esac
  case "$TOOL_INPUT" in
    *--fix*) in_main_checkout "$CWD" && vote ask G3 "code-review --fix in the main checkout edits shared files" ;;
  esac
}

_g03_post() {
  if [ "$AUTOPILOT" = 1 ]; then
    vote deny G3 "$1 under autopilot: review posting stays human"
    return 0
  fi
  case "$(policy_for review.post)" in
    auto) vote allow G3 "review.post_policy auto: $1" ;;
    deny) vote deny G3 "review.post_policy deny" ;;
    *) vote ask G3 "$1 posts to the PR" ;;
  esac
}

# _g03_labelled FILE: the first non-empty line starts with a review.taxonomy label.
_g03_labelled() {
  local tax first rest label
  [ -f "$1" ] || return 1
  tax=$(settings_get review.taxonomy "blocker,should-fix,nit,pre-existing")
  first=$(sed -n '/[^[:space:]]/{p;q;}' "$1" | sed 's/^[[:space:]*#>-]*//' | tr '[:upper:]' '[:lower:]')
  rest="$tax,"
  while [ -n "$rest" ]; do
    label=${rest%%,*}; rest=${rest#*,}
    label=$(printf '%s' "$label" | sed 's/^[[:space:]]*//; s/[[:space:]]*$//' | tr '[:upper:]' '[:lower:]')
    [ -n "$label" ] || continue
    case "$first" in "$label"*) return 0 ;; esac
  done
  return 1
}

_g03_review() {
  local words num me author file
  words=$(_shell_words "$1")
  if word_has "$words" --approve -a; then
    num=$(printf '%s\n' "$words" | awk 'f && /^[0-9]+$/ { print; exit } $0 == "review" { f = 1 }')
    if command -v gh >/dev/null 2>&1 &&
      me=$( (cd "$CWD" && with_timeout 10 gh api user --jq .login) 2>/dev/null) &&
      author=$( (cd "$CWD" && with_timeout 10 gh pr view ${num:+"$num"} --json author --jq .author.login) 2>/dev/null) &&
      [ -n "$me" ] && [ "$me" = "$author" ]; then
      vote deny G3 "self-approval: use a COMMENT review on your own PR"
      return 0
    fi
    _g03_post "gh pr review --approve"
    return 0
  fi
  file=$(word_value "$words" --body-file -F) || file=""
  if [ -n "$file" ]; then
    case "$file" in /*) ;; *) file="$CWD/$file" ;; esac
    if ! _g03_labelled "$file"; then
      vote deny G3 "review body must open with a review.taxonomy label ($(settings_get review.taxonomy "blocker,should-fix,nit,pre-existing"))"
      return 0
    fi
  fi
  _g03_post "gh pr review"
}

_g03_api() {
  local words file tax b ok=1
```

```bash
# shellcheck shell=bash
# G5 commit: message convention and attribution checks, explicit staging, commit.policy.

guard_g05() {
  [ "$TOOL" = Bash ] || return 0
  local cmd seg parsed dir sub rest
  cmd=$(ti_get command) || return 0
  while IFS= read -r seg; do
    parsed=$(git_sub "$seg") || continue
    dir=${parsed%%	*}
    rest=${parsed#*	}
    sub=${rest%%	*}
    case "$sub" in
      add) _g05_add "$seg" ;;
      commit) _g05_commit "$dir" "$seg" ;;
    esac
  done <<EOT
$(git_words "$cmd")
EOT
}

_g05_broad() {
  vote ask G5 "$1 stages every change; stage named files with git add -- <paths>"
  [ "$AUTOPILOT" = 1 ] && vote deny G5 "$1 under autopilot"
}

_g05_add() {
  local words
  words=$(_shell_words "$1" | awk 'f { print } $0 == "add" { f = 1 }')
  if word_has "$words" -A --all . :/ -u --update '*'; then
    _g05_broad "git add -A"
  fi
}

# _g05_message DIR WORDS: prints the commit message. Exit 1 when it cannot be read statically.
_g05_message() {
  local dir="$1" words="$2" w prev="" msg="" have=0 f ref
  while IFS= read -r w; do
    case "$prev" in
      -m | --message) msg="${msg:+$msg

}$w"; have=1; prev=""; continue ;;
      -F | --file) f="$w"; prev=""; continue ;;
      -C | -c | --reuse-message | --reedit-message) ref="$w"; prev=""; continue ;;
    esac
    case "$w" in
      -m | --message | -F | --file | -C | -c | --reuse-message | --reedit-message) prev="$w" ;;
      --message=*) msg="${msg:+$msg

}${w#--message=}"; have=1 ;;
      --file=*) f="${w#--file=}" ;;
      -m?*) msg="${msg:+$msg

}${w#-m}"; have=1 ;;
      -F?*) f="${w#-F}" ;;
    esac
  done <<EOT
$words
EOT
  if [ -n "${f-}" ]; then
    [ "$f" = - ] && return 1
    case "$f" in /*) ;; *) f="$dir/$f" ;; esac
    [ -f "$f" ] || return 1
    cat "$f"
    return 0
  fi
  if [ "$have" = 1 ]; then
    case "$msg" in *'$('* | *'`'*) return 1 ;; esac
    printf '%s\n' "$msg"
    return 0
  fi
  if [ -n "${ref-}" ]; then
    git -C "$dir" log -1 --format=%B "$ref" 2>/dev/null
    return $?
  fi
  if word_has "$words" --no-edit && word_has "$words" --amend; then
    git -C "$dir" log -1 --format=%B 2>/dev/null
    return $?
  fi
  return 1
}

# _g05_problems DIR MESSAGE: one line per failed check; nothing when the message passes.
_g05_problems() {
  local dir="$1" msg="$2" subject conv idre branch id
  subject=$(printf '%s\n' "$msg" | sed -n '/[^[:space:]]/{p;q;}')
  if [ "$(settings_get commit.attribution none)" = none ] &&
    printf '%s\n' "$msg" | grep -Eiq 'co-authored-by:.*(claude|anthropic)|generated (with|by) .*claude|claude-session:|claude\.ai/code'; then
    echo "attribution trailer present (commit.attribution: none)"
  fi
  conv=$(settings_get commit.convention '')
  if [ -n "$conv" ] && ! printf '%s\n' "$subject" | grep -Eq -- "$conv"; then
    echo "subject does not match commit.convention $conv"
  fi
  idre=$(settings_get commit.id_from_branch '[A-Z][A-Z0-9]+-[0-9]+')
  branch=$(current_branch "$dir")
  id=$(printf '%s\n' "$branch" | grep -Eo -- "$idre" | head -n 1)
  if [ -n "$id" ]; then
    case "$subject" in *"$id"*) ;; *) echo "subject lacks the ticket id $id from branch $branch" ;; esac
  fi
}

_g05_commit() {
  local dir="$1" words msg problems
  words=$(_shell_words "$2" | awk 'f { print } $0 == "commit" { f = 1 }')
  if word_has "$words" -a --all || printf '%s\n' "$words" | grep -Eq '^-[a-zA-Z]*a[a-zA-Z]*$'; then
    _g05_broad "git commit -a"
  fi
  if ! msg=$(_g05_message "$dir" "$words"); then
    vote ask G5 "commit message cannot be checked here; write it to a file and use git commit -F <file>"
    return 0
  fi
  problems=$(_g05_problems "$dir" "$msg")
  if [ -n "$problems" ]; then
    vote deny G5 "$(printf '%s\n' "$problems" | paste -sd ';' - | sed 's/;/; /g')"
    return 0
  fi
  case "$(policy_for commit)" in
    deny) vote deny G5 "commit.policy deny" ;;
    auto) vote allow G5 "commit.policy auto: message checks pass" ;;
    *)
      if [ "$AUTOPILOT" = 1 ]; then
        vote allow G5 "autopilot commit: message checks pass"
      else
        vote ask G5 "commit (message checks pass)"
      fi
      ;;
  esac
}
```

```bash
# shellcheck shell=bash
# G6 secrets: scan what a commit or push would publish; refuse never_commit paths.

guard_g06() {
  [ "$TOOL" = Bash ] || return 0
  local cmd seg parsed dir sub rest
  cmd=$(ti_get command) || return 0
  while IFS= read -r seg; do
    parsed=$(git_sub "$seg") || continue
    dir=${parsed%%	*}
    rest=${parsed#*	}
    sub=${rest%%	*}
    rest=${rest#*	}
    case "$sub" in
      commit) _g06_commit "$dir" "$rest" ;;
      push) _g06_push "$dir" ;;
    esac
  done <<EOT
$(git_words "$cmd")
EOT
}

# _g06_added: reads a unified diff, prints `path:line:text` for every added line.
_g06_added() {
  LC_ALL=C awk '
    /^\+\+\+ / { p = substr($0, 5); sub(/^b\//, "", p); next }
    /^@@ / { split($3, a, ","); ln = substr(a[1], 2) + 0; next }
    /^\+/ { print p ":" ln ":" substr($0, 2); ln++; next }
    /^ / { ln++ }'
}

# _g06_scan: reads `path:line:text` lines, prints `path:line <rule>` per hit. Never prints the text.
_g06_scan() {
  local added rule re
  added=$(cat)
  [ -n "$added" ] || return 0
  while IFS='|' read -r rule re; do
    printf '%s\n' "$added" | grep -E -- "$re" | cut -d: -f1,2 | sed "s/\$/ $rule/"
  done <<'EOT'
private-key|-----BEGIN [A-Z ]*PRIVATE KEY-----
aws-access-key|AKIA[0-9A-Z]{16}
github-token|gh[pousr]_[A-Za-z0-9]{20,}
slack-token|xox[baprs]-[A-Za-z0-9-]{10,}
api-key|sk-[A-Za-z0-9_-]{20,}
google-api-key|AIza[0-9A-Za-z_-]{35}
EOT
}

# _g06_paths NAMES: deny when a newline-separated path matches a never_commit glob.
_g06_paths() {
  local list glob name rest hits=""
  list=$(settings_get never_commit '')
  [ -n "$list" ] || return 0
  while IFS= read -r name; do
    [ -n "$name" ] || continue
    rest="$list,"
    while [ -n "$rest" ]; do
      glob=${rest%%,*}
      rest=${rest#*,}
      glob=$(printf '%s' "$glob" | sed 's/^[[:space:]]*//; s/[[:space:]]*$//')
      [ -n "$glob" ] || continue
      # shellcheck disable=SC2254
      case "$name" in $glob) hits="${hits:+$hits, }$name" ;; esac
    done
  done <<EOT
$1
EOT
  [ -n "$hits" ] && vote deny G6 "never_commit paths staged: $hits"
  return 0
}

_g06_report() {
  local hits="$1" diff="$2"
  if [ -n "$hits" ]; then
    vote deny G6 "possible secret, not committed or pushed: $(printf '%s\n' "$hits" | head -n 5 | paste -sd ';' - | sed 's/;/; /g')"
  elif command -v gitleaks >/dev/null 2>&1; then
    printf '%s\n' "$diff" | gitleaks stdin --no-banner --redact >/dev/null 2>&1
    [ $? -eq 1 ] && vote deny G6 "gitleaks reports a secret in this change; run gitleaks yourself to see where"
  fi
}

_g06_commit() {
  local dir="$1" rest="$2" diff names
  diff=$(git -C "$dir" diff --cached 2>/dev/null)
  names=$(git -C "$dir" diff --cached --name-only 2>/dev/null)
  case " $rest " in
    *" -a "* | *" --all "* | *" -am "*)
      diff="$diff
$(git -C "$dir" diff 2>/dev/null)"
      names="$names
$(git -C "$dir" diff --name-only 2>/dev/null)"
      ;;
  esac
  _g06_paths "$names"
  _g06_report "$(printf '%s\n' "$diff" | _g06_added | _g06_scan)" "$diff"
}

_g06_push() {
  local dir="$1" range base diff
  if git -C "$dir" rev-parse --verify -q '@{u}' >/dev/null 2>&1; then
    range='@{u}..HEAD'
  elif base=$(base_branch_name); then
    range="origin/$base..HEAD"
  else
    return 0
  fi
  diff=$(git -C "$dir" log -p --format= "$range" 2>/dev/null)
  _g06_paths "$(git -C "$dir" diff --name-only "$range" 2>/dev/null)"
  _g06_report "$(printf '%s\n' "$diff" | _g06_added | _g06_scan)" "$diff"
}
```

```bash
# shellcheck shell=bash
# G13 protected targets: no copies to, and no mutating SQL against, anything in protected_targets.
# Reading (SELECT, scp from the target, sftp get) stays allowed.

guard_g13() {
  [ "$TOOL" = Bash ] || return 0
  local list cmd seg rest target
  list=$(settings_get protected_targets '')
  [ -n "$list" ] || return 0
  cmd=$(ti_get command) || return 0
  rest="$list,"
  while [ -n "$rest" ]; do
    target=${rest%%,*}
    rest=${rest#*,}
    target=$(printf '%s' "$target" | sed 's/^[[:space:]]*//; s/[[:space:]]*$//')
    [ -n "$target" ] || continue
    case "$cmd" in *"$target"*) ;; *) continue ;; esac
    while IFS= read -r seg; do
      _g13_segment "$seg" "$target"
    done <<EOT
$(git_words "$cmd")
EOT
    _g13_sql "$cmd" "$target"
  done
}

_g13_segment() {
  local seg="$1" target="$2" head last
  head=$(cmd_head "$seg")
  case "${head%% *}" in
    scp | rsync)
      last=$(_shell_words "$seg" | tail -n 1)
      case "$last" in *"$target"*) vote deny G13 "copy to protected target $target" ;; esac
      ;;
    sftp)
      printf '%s\n' "$seg" | grep -Eiq '(^|[^a-z])(put|rm|rename|mkdir|rmdir|chmod)[[:space:]]' &&
        vote deny G13 "sftp write to protected target $target"
      ;;
    ssh)
      case "$seg" in *"$target"*) ;; *) return 0 ;; esac
      _shell_words "$seg" | paste -sd ' ' - | grep -Eq '(^|[[:space:];])(rm|mv|cp|del|copy|move|rename|mkdir|rmdir|touch|tee|chmod|chown|systemctl|service|kill)([[:space:];]|$)|>' &&
        vote deny G13 "write command over ssh to protected target $target"
      ;;
  esac
}

# _g13_sql CMD TARGET: mutating SQL in the command, or in a file it feeds with -f, --file or <.
_g13_sql() {
  local cmd="$1" target="$2" text f
  text="$cmd"
  for f in $(printf '%s\n' "$cmd" | grep -Eo '(-f|--file=?|<)[[:space:]]*[^[:space:];|&]+\.sql' | sed -E 's/^(-f|--file=?|<)[[:space:]]*//'); do
    case "$f" in /*) ;; *) f="$CWD/$f" ;; esac
    [ -f "$f" ] && text="$text
$(cat "$f")"
  done
  printf '%s\n' "$text" | grep -Eiq '(^|[^a-z_])(insert[[:space:]]+into|update[[:space:]]+[a-z_."`]+[[:space:]]+set|delete[[:space:]]+from|drop[[:space:]]+(table|database|schema|index|view)|alter[[:space:]]+(table|database|schema)|truncate|create[[:space:]]+(table|database|schema|index)|grant[[:space:]]|revoke[[:space:]]|lock[[:space:]]+tables|set[[:space:]]+global|kill[[:space:]]+[0-9])' &&
    vote deny G13 "mutating SQL against protected target $target"
  return 0
}
```

```bash
# Runs every hook over the fixture projects in tests/fixtures/projects (lint rule 15).
# Per case: SessionStart output holds each line of expect.txt (or is empty for <empty>);
# SubagentStart prints valid JSON within 1,200 characters; UserPromptSubmit and PreToolUse
# exit 0 and print nothing or valid JSON.
set -euo pipefail
ROOT="$(cd "$(dirname "$0")/.." && pwd)"
TMP=$(mktemp -d)
trap 'rm -rf "$TMP"' EXIT
fail=0
cases=0

json_ok() {
  node -e 'let s="";process.stdin.on("data",d=>s+=d).on("end",()=>{if(!s.trim())process.exit(0);JSON.parse(s)})'
}

for dir in "$ROOT"/tests/fixtures/projects/*/; do
  name=$(basename "$dir")
  cases=$((cases + 1))
  repo="$TMP/$name/repo"
  mkdir -p "$repo/.claude" "$TMP/$name/home/.claude"
  git init -q "$repo"
  for f in kern.local.yml kern.yml; do
    [ -f "$dir/$f" ] && cp "$dir/$f" "$repo/.claude/$f"
  done
  export HOME="$TMP/$name/home" CLAUDE_PLUGIN_DATA="$TMP/$name/data"
  base="\"session_id\":\"shape-$name\",\"cwd\":\"$repo\""
  out=$(printf '{%s,"hook_event_name":"SessionStart","source":"startup"}' "$base" | bash "$ROOT/hooks/session-start")
  while IFS= read -r want; do
    [ -n "$want" ] || continue
    if [ "$want" = "<empty>" ]; then
      [ -z "$out" ] || { echo "FAIL $name: expected no output"; fail=1; }
    elif [[ "$out" != *"$want"* ]]; then
      echo "FAIL $name: missing: $want"

  sub=$(printf '{%s,"hook_event_name":"SubagentStart","agent_id":"a","agent_type":"Explore"}' "$base" | bash "$ROOT/hooks/subagent-start")

  printf '{%s,"hook_event_name":"UserPromptSubmit","prompt":"hello"}' "$base" | bash "$ROOT/hooks/prompt-submit" >/dev/null ||
    { echo "FAIL $name: prompt-submit exited non-zero"; fail=1; }
  pre=$(printf '{%s,"hook_event_name":"PreToolUse","tool_name":"Bash","tool_input":{"command":"git status"}}' "$base" | bash "$ROOT/hooks/pre-tool-use")
  printf '%s' "$pre" | json_ok || { echo "FAIL $name: PreToolUse output is not JSON"; fail=1; }
```
