Release 0.2.1 · 14 Oct

What the source audit and three review rounds fixed

safety

With a hook library missing, kern made no decision, so a force push to main went through unguarded. Hooks now ask, or deny under bypassPermissions, when any library or function fails to load.

voice

The first fix made 27 everyday prompts switch the voice, such as "use terse variable names". Under the stop rule it was redesigned: a switch fires only when the phrase stands alone on the first line. 200 cases test it.

quiet

Scheduled-task prompts get no mode line or terse reminder.

tidy

Session state files untouched for 30 days are removed at session start.

Master goal · design spec goal 0

Kern must beat each source in its own category

For each category of work, kern is at least as strong as the strongest of its five sources, with the strongest mechanism enforced in code where code can.

Measured three ways: a coverage re-audit at each milestone close that counts only built and tested work, head-to-head evals on seeded fixtures for planning, debugging and review, and side-by-side pilot runs against superpowers.
