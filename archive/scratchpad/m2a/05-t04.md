- Create: `scripts/wt-audit`

**Interfaces:**
- Consumes: `wt_dir` (Task 1); `kern-detect base_branch` (M1); `gh pr list --head <branch> --state all --json state --jq '.[].state'` when `gh` is installed.
- Produces: `wt-audit [--days N]`: one line per kern worktree under `worktree.dir`, `bucket<TAB>path<TAB>branch<TAB>evidence`; buckets `merged`, `open-pr`, `closed-pr`, `uncommitted`, `committed`, `empty`; a detached worktree shows `(detached)`; a worktree with no commit and no file change in N days (default 14) gets `idle <N>d or more`. Read-only: git runs with `--no-optional-locks` and no fsmonitor, so no index is refreshed. Exit 0; 2 on a usage error or outside a git repository. recall step 3 and every teardown proposal read it.
