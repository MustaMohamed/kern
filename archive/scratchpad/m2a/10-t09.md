
### Task 9: Review lines and task completion

**Files:**
- Create: `scripts/task-review`, `scripts/task-done`
- Test: `tests/scripts/task-done.bats`

**Interfaces:**
- Consumes: `wt-snap`, `wt-diff` (Task 2); `probe --exclude-tests` (Task 6); a ledger from `ledger-open` (Task 8).
- Produces:
  - `task-review LEDGER N TREE ROUND SPEC QUALITY [--minor TEXT]...`: SPEC is `compliant` or `issues`, QUALITY `approved` or `needs-fixes`, ROUND `1`, `2` or `3`. Appends and prints `Task N: review round=<r> tree=<id> spec=<s> quality=<q>`, then one `Task N: minor (deferred): <text>` line per `--minor`. Exit 2 on any malformed argument, writing nothing.
  - `task-done LEDGER N WT TREE [--probe PATCH] -- CMD...`: exit 2, writing nothing, when `wt-snap WT` is not TREE or task N's last review line is not `... tree=TREE spec=compliant quality=approved`. Runs CMD in WT, keeps its output in `<ledger dir>/logs/task-N.log` and prints the last 5 lines; CMD's code when it fails. With `--probe PATCH`, then runs `probe --exclude-tests WT PATCH -- CMD`: exit 1 (writing nothing) when the test passes with the change reversed. On success appends `Task N: complete tree=<id> test=<cmd> exit=0 review=approved probe=<ok|inconclusive|none> last=<last non-blank output line>`.
