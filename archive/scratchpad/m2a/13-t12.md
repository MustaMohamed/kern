**Interfaces:**
- Consumes (M1): the dispatcher `hooks/pre-tool-use` sets `TOOL`, `AGENT` (from `agent_type`, empty when absent) and `TOOL_INPUT`, sources every `hooks/guards/*.sh`, calls `guard_<id>`, and fails closed for an id in `KERN_GUARD_IDS` whose function is missing; `ti_get KEY`; `git_words CMD` (one simple command per line; a `2>&1` stays inside its command, measured); `git_sub CMDLINE` (`<dir><TAB><subcommand><TAB><rest>`); `vote deny G<n> REASON`.
- Produces: `guard_g18` (votes `deny` only; never `allow`, so the normal permission flow still applies to allowed commands) and `g18_allowed SIMPLE_COMMAND` (exit 0 when the command only reads). `G18_AGENTS="kern:investigator"`, the value the M1 spike recorded (path A: the investigator keeps Bash). Denied: anything off the allowlist; a redirect to a file; `$( )` and backticks; git with `-c`, `--config-env`, `-O`, `--open-files-in-pager`, `--output`, `--ext-diff` or `--textconv`; `rg --pre` or `-z`; `file -C` or `--compile`; `sort` with `-o` in any option cluster, `--output` or `--compress-program`; `find -delete`, `-exec`, `-execdir`, `-ok`, `-fprint`, `-fls`; `sed` other than `sed -n` with a script of line numbers and `p`. `uniq` is off the list (its second operand is an output file).

If a later Claude Code stops sending `agent_type`, G18 never fires.
