
### Task 2: Snapshot trees, review packages and allowed paths

**Files:**
- Create: `scripts/wt-snap`, `scripts/wt-diff`
- Test: `tests/scripts/wt-snap-diff.bats`

**Interfaces:**
- Consumes: `tests/helpers/wt.bash` (Task 1); `scripts/kern-dir SUB` (M1) for the default package location.
- Produces:
  - `wt-snap WT`: prints the tree id of WT's working state (tracked and untracked files, ignore rules applied); exit 0, 2 on error. Touches no ref and not the real index.
  - `wt-diff WT FROM_TREE [TO_TREE] [--out FILE] [--allow PATH]... [--allow-file FILE]`: writes the package and `<package>.patch`; prints the package path, then TO_TREE, then one changed path per line; exit 0, 3 on an empty diff, 2 on error. With `--allow` or `--allow-file` (one path per line), a changed path no entry covers is printed to stderr as `wt-diff: outside the allowed paths: <path>` and the exit is 4; the package is still written. An entry covers the same path, or every path under it when it ends in `/`. Default package path: `WORK/reviews/<from7>..<to7>.diff`.
