
### Task 14: Guard G20, approvals that quote the user

**Files:**
- Create: `hooks/guards/g20-approval.sh`
- Modify: `hooks/lib/state.sh` (append `prompt_hashes`), `hooks/prompt-submit` (record the hashes), `hooks/pre-tool-use` (`KERN_GUARD_IDS`, one `need` line), `hooks/session-start` (one `need` line), `CHANGELOG.md`
- Test: `tests/hooks/g20.bats`

**Interfaces:**
- Consumes (M1): `state_set`, `state_get`, `state_file` (state.sh); `settings_get work_dir`; `ti_get`; `git_words`; `vote`; the dispatcher's `TOOL`, `CWD`, `SID`, `KERN_MAIN`, `AUTOPILOT`; `wrapped` in prompt-submit.
- Produces:
  - `prompt_hashes` (state.sh): reads text on stdin; prints, space-separated, one hash per non-blank line of up to 500 characters (the first 20 such lines), after lowercasing, folding blanks to one space, trimming and dropping a final run of `.` and `!`.
  - Session state key `prompt_hashes: <hashes>`, rewritten by prompt-submit on every user prompt that is not wrapped (a task notification, a cross-session, teammate, channel or agent message, or a scheduled task records nothing). G16 already denies any tool write to the state file.
  - `guard_g20`: on a Write or Edit of a `.md` file under `WORK/specs/` or `WORK/plans/` whose new text has a `status: approved` line: deny under autopilot; deny when no `approved:` line with a double-quoted quote is in the new text or the file; deny when the quote, normalized, is on the non-answer list (`sounds good`, `whatever you think`, `whatever`, `up to you`, `your call`, `you decide`, `i guess`, `maybe`, `not sure`, `looks fine i guess`); deny when its hash is not among the user's last prompt's hashes; deny when the file is newer than the state file (the draft changed after that prompt). On a Bash command that names `WORK/specs/` or `WORK/plans/`, holds the word `approved` and writes (a redirect to a file, `sed -i`, `tee`, `cp`, `mv`, `install`, `dd`, `ed`, `ex`, `truncate` or a script interpreter): deny. G20 never votes allow. Accepted limit: a write that hides both the path and the word, such as a script file run by name, is not seen; `ledger-open` still refuses a plan with no quoted approval.
